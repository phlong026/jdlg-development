# 恢复原首页并保留快捷估算

用户确认的顺序：原山水品牌区 → AI 入口 → 乡村别墅、城市更新、造价测算、综合设计四张卡片 → 可操作的「10秒估算建房报价」表单 → 精选案例对比。

## 实施与清理计划

1. 先用失败的布局回归测试锁定四张卡片的顺序、路由，以及估算表单位于卡片与案例之间。
2. 只恢复旧首页的展示层和原素材；删除当前八入口品牌区的无用布局与安全距离代码。保留现有客服、登录衔接、案例、估算校验和参数传递逻辑。
3. 将当前快捷估算表单整体移到四张卡片下方，保留原事件绑定，不恢复已废弃的建房报告占位卡片。
4. 独立核查朋友圈菜单、分享入口、标题封面和内容参数；仅对可复现问题先补测试再修复。
5. 运行小程序测试、语法与类型检查、样式编译、安全扫描、依赖审计和差异审查；在微信开发者工具检查展示及表单交互，并记录真机验证边界。

## 素材与回滚

旧首页来自工作区 `需求文档/首页视觉方案/20261008-用户确认复刻/原首页备份`，清单19项文件已在本会话逐项核对 SHA-256。复用原有 CDN 素材，不增加依赖。

变更集中在小程序首页展示、分享相关文件及其测试。原始备份与其他工作树保持独立。回滚使用本次提交的 `git revert`，不涉及数据库迁移或服务配置。

### 分享行为

公开页面和已有显式朋友圈回调的业务页面开放入口。默认分享只使用路由清单已审查的 idKey/idAlias，不复制全部启动参数；估算表单的省市、面积不进入默认分享。订单、钱包、身份、私密报告和未知页面默认隐藏朋友圈；无自定义好友分享时回到首页。邀请码、生成任务编号和方案 ID 按各页面自己的分享逻辑保留。

首页移除了旧八入口品牌布局、相关安全距离计算和重复的 onLoad 分享菜单调用；分享菜单由统一生命周期处理，避免在微信单页模式调用禁用 API。
