# 内容导入启用与自建内容删除

基线：bc5405b；分支：feat/content-import-delete-20261105。用户已授权接通生产导入并为自建内容增加长按或侧滑删除。

## 实施任务

1. 核验生产导入任务表、COS与已有解析凭据；接入已运行采集Worker的四项私密客户端配置并启用CONTENT_IMPORT_ENABLED。配置/进程操作保留私密备份和自动失败回退，真实凭据不入Git。
2. 用用户自有或授权链接验收提交、解析、媒体私有归档、可编辑草稿与重启恢复。仅启用真正可用的平台；上游风控、过期登录态、解析失败明确展示，不能把readiness当作导入成功。
3. 项目与项目笔记：长按操作菜单和二次确认；项目逻辑删除后列表移除，详情/编辑/加入/旧私密分享及资料包拒绝访问。保留冻结历史与媒体，不扩大普通成员权限。
4. 内容与合集：保留旧草稿删除接口契约，补通用逻辑删除；已发布内容删除时旧公开入口失效，账号、归属和revision在事务内复核。
5. 资料库引用仅移除自身引用；作品和生成记录复用已有删除、确认及侧滑能力，增加一致的长按入口。长按不误打开，取消不删除，旧账号/旧列表回调不执行。
6. TS/JS产物同步、行为先失败再实现、WXML/类型/全量相关测试/Go vet、凭据扫描、差异审查和回退检查。分项中文提交并推送；部署后端，上传小程序7.4.3并核验体验版状态。正式提审发布单独报告实际状态。

## 写入边界

- 项目代理：projectnotes页面、project_note相关Go服务与路由和访问门禁测试。
- 内容代理：内容/合集/资料库/作品/生成记录页面，内容和合集删除Go服务、路由及测试，project-collections-api。
- 配置代理：独立import_activation发布工具、测试及说明；不操作生产。
- 主代理：共享phase3-api客户端、生产核验/配置启用、真实链接验收、集成复核及提交部署。

## 验收边界

真实用户的已有项目和作品不用于删除测试；只使用本次新建的验收对象。删除入口不物理删除共享媒体；任何可继续读取已删除项目或内容的旧入口均视为未完成。导入生成草稿不自动发布。真实外部链接尚待用户提供，其他工作继续独立推进。
