# 设计师工作台独立「AI视频」开发任务书与验收标准 V2

> **For agentic workers:** 实施时逐项执行并保留测试与验收证据；本文件是开发任务书，不代表功能已经实施、联调或上线。所有 `- [ ]` 均为未实施任务。

**Goal:** 在甲地灵光设计师工作台单独新增「AI视频」模块，提供文生视频、首帧图生视频、首尾帧生成和图片/视频/音频混合参考生成，并完成草稿、任务、费用、成片及内容使用闭环。

**Architecture:** 新模块拥有独立入口、页面、草稿、任务与创作记录。甲地灵光服务端统一处理身份、归属、报价、计费、任务恢复和内容关联，通过适配层调用已验证的视频生成能力。现有账号、上传、媒体播放、内容草稿等基础设施按适用性复用；既有 `pages/aivideo/aivideo` 继续作为原功能，不承担本次新增模块。

**Tech Stack:** 微信小程序 WXML、SCSS/WXSS、TypeScript/JavaScript；Go/Gin、MySQL；现有管理台 React/TypeScript。能力接入方式在 T01 冻结，不直接复制参考项目页面、数据库、账号或钱包。

**Spec:** 用户 2026-11-13 的新增模块需求及同日范围补充，含最新工作台入口顺序：我的项目、内容创作、AI 视频、客户跟踪；任务、验收、依赖和交付边界以本文为准。

### 1.2 本次交付范围

1. **文生视频：** 输入画面描述，选择合法比例、时长、清晰度和数量后生成。

### 1.3 明确不包含

- 不建设爆款视频爬取、榜单、定时采集或跨平台自动发布系统。
- 不承诺所有外部平台分享链接均能解析；没有合法稳定能力时使用本地上传或本人素材。
- 不开放纯尾帧生成；仅在服务端明确开放时支持首尾帧组合。
- 不将生成成功自动解释为已保存素材、已发布内容或已写入项目笔记。
- 不共用参考系统客户登录态、客户钱包或数据库业务真源。

- [ ] **T06 — 新创作素材上传。**
  - 任务：支持图片、视频和音频上传，适用时复用分片上传；展示真实进度、取消、失败和重传；服务端检查媒体类型、大小、时长与完整性。
  - 验收：合法文件上传完成后可选用；伪扩展名、损坏和越限文件在付费调用前被拒绝并说明原因；失败保留当前表单；中断不会生成假可用素材或重复有效记录。

- [ ] **T07 — 从现有素材选择与返回。**
  - 任务：按图片、视频和音频查询有权使用的素材，支持搜索、分页、预览和取消；区分首帧、尾帧和混合参考用途。
  - 验收：选择结果只回填发起位置；取消不修改草稿；他人私密或不适用素材不可选；返回后创作参数和已选顺序保持；素材加载失败可单独重试。

- [ ] **T08 — 提示词编辑与「我的提示词」。**
  - 任务：支持手写、复制、命名保存、分页查询、导入和删除本人提示词；保留来源、适用模式和必要上下文。

- [ ] **T09 — AI 优化与采用结果。**
  - 任务：提供普通画面描述优化和混合参考结构化提示词整理；显示原文与结果，允许编辑、采用或放弃；单独展示费用与执行状态。
  - 验收：未点采用不覆盖原稿；失败保留原文；更换账号、草稿或修订后不回填旧结果；人工合法提示词可按能力直接提交，AI 优化不是无条件强制前置。

- [ ] **T10 — 素材编号、用途与引用一致性。**
  - 任务：按选择顺序显示引用编号并填写主体、空间、动作、音色等用途；增删或重排素材时重建引用并提示重新核对提示词。
  - 验收：三类素材混合时编号和实际请求绑定一致；移除中间素材不把原引用静默指向另一项；失效素材不能直接提交；音频用途说明不伪称系统已理解全部音轨内容。

### C. AI 视频生成：8 项

- [ ] **T11 — 文生视频。**
  - 任务：只用画面描述创建视频，允许选择服务端开放的比例、时长、清晰度和数量，不继承原页面必须上传图片的约束。
  - 验收：无图片和参考素材也能按已开放能力生成；空提示词拒绝；请求不携带残留图片；文生模式不能提交不支持的自动比例；确认页参数与订单一致。

- [ ] **T12 — 首帧图生视频。**
  - 任务：上传或选用一张首帧，预览并结合画面描述生成；比例按图片和服务端规则确定，页面显示实际提交值。
  - 验收：所见首帧与请求一致；替换/移除图片后报价和提示词核对状态更新；预览失败可重试；没有有效首帧时不能误按图生模式提交。

- [ ] **T13 — 首尾帧生成。**
  - 任务：在首帧基础上可选尾帧；能力开放时提交组合，能力关闭时隐藏或禁用合法入口；不提供纯尾帧提交。
  - 验收：首尾帧均能预览且与请求一致；服务端关闭能力后旧草稿不能绕过；仅尾帧在前后端均拒绝；切换图片后参数、报价和核对状态同步更新。

- [ ] **T14 — 混合参考生成。**
  - 任务：选择图片、视频和音频参考素材，标注用途，生成或编辑结构化提示词并按准确绑定提交；与首尾帧模式分仓保存。
  - 验收：至少一项合法参考方可提交；图片、视频、音频单类和混合场景均可运行；不能同时夹带首尾帧；重复、失效或错位引用在付费调用前阻止。

- [ ] **T15 — 能力驱动的参数控件。**
  - 任务：从后端读取模式、清晰度、时长、比例、数量和素材限制；对标 768P/2K、基础 4–15 秒及受控 16–30 秒长档，渲染实际可用组合。
  - 验收：能力加载、失败、关闭三种状态可区分；2K 不能提交超过 15 秒；关闭长档后旧草稿不能提交 30 秒；数量和比例以后端限制为准。

- [ ] **T16 — 素材及组合校验。**
  - 任务：按已验证能力执行图片≤8、视频≤3、音频≤3、总数≤12；视频/音频单条 2–15 秒，各类累计≤15 秒；校验真实类型、权限与引用。
  - 验收：覆盖每类刚好上限和超一项、2/15 秒及越界、累计 15 秒及超限；页面、草稿恢复和服务端结果一致；篡改请求不能绕过；未知时长先探测再提交。

- [ ] **T17 — 生成报价与确认。**
  - 任务：显示名称、模式、时长、清晰度、数量和预计/最高费用；取服务端报价并冻结输入快照，参数变化后重新报价。
  - 验收：取消不扣费；报价过期、余额不足或档位关闭不能误建单；价格展示单价和计费数量/秒数；实际流水能与确认内容逐项核对。

- [ ] **T18 — 批次提交、状态与结果。**
  - 任务：幂等创建单条/多条批次，持久记录每个子任务；展示排队、提交、生成、交付准备及终态，就地显示逐条结果和继续创作入口。
  - 验收：连续点击或响应丢失重试只有一个批次；重启后不靠页面内存继续；部分成功保留成功项并展示失败原因；状态待确认不伪装明确失败；DIRECT 结果不因暂无留存媒体 ID 被误判失败。

### D. 创作记录与业务使用：5 项

- [ ] **T19 — 独立创作记录与筛选。**
  - 任务：统一列出本模块草稿、生成批次和结果；按模式、状态、关键词和时间分页查询，显示最近操作和可继续动作。
  - 验收：离开重进可找到全部已提交任务；新模块记录默认不混入原 AI 视频记录；空态、加载、无结果和失败态不同；批次与子任务数量一致。

- [ ] **T20 — 任务详情、来源和再创作。**
  - 任务：展示输入快照、素材引用、提示词版本、参数、步骤状态、错误、费用和尝试关系；支持按原输入创建新草稿。
  - 验收：原任务快照不被当前编辑覆盖；明示再创作会新建任务及是否收费；跨账号改任务 ID 拒绝；素材停用后仍可看必要历史但不能重新提交非法引用。

- [ ] **T21 — 视频播放与下载。**
  - 任务：提供适用于小程序的授权播放、拖动、重新获取有效地址及下载/保存相册；区分直链交付和已稳定留存结果。
  - 验收：真实设备可播放、拖动和下载；地址失效可按权限刷新；相册权限拒绝、网络失败和媒体失效有准确反馈；不把复制链接当作保存相册成功。

- [ ] **T22 — 显式保存到创作素材。**
  - 任务：用户点击保存时归档或复用已留存媒体，创建本人可用素材，保留来源、封面和时长；记录留存中、失败和完成。
  - 验收：生成成功不自动等于已保存；保存后重进素材页可用；重复保存不产生重复有效素材；留存失败可续办且不重新收取生成费；临时 URL 不算长期素材完成。

- [ ] **T23 — 用于内容与项目。**
  - 任务：将已留存视频创建为内容草稿，或经用户选定插入有编辑权限的项目笔记；保留来源关系及草稿身份/修订校验。
  - 验收：只创建草稿或插入选定位置，不自动发布；原正文、封面和其他内容块不被覆盖；账号、笔记、草稿实例或修订变化时拒绝旧回填；公开内容和私密项目沿用各自权限。

### E. 后台配置、费用与可靠性：5 项

- [ ] **T24 — 能力、供应商和运行配置。**

  - 验收：关闭某能力立即禁止新提交但仍可查询历史；缺配置显示真实未开放状态；前端、API 和日志不返回密钥；错误可按任务定位且不暴露无助于用户决策的内部信息。

- [ ] **T25 — 独立价格目录与报价规则。**
  - 任务：配置提示词优化和各视频生成档位的收费项，明确按次、条或秒计价；对接既有灵石体系并区分新模块来源。
  - 验收：报价、确认、提交和账务同口径；改价只影响新报价；未配置/停用项目不能以零费放行；不直接复制参考积分或原视频功能的固定价格。

- [ ] **T26 — 扣费、结算、释放与对账。**
  - 任务：持久保存收费快照、预留、成功结算和失败释放/退款；按批次和子任务关联账务，记录已交付待核对状态。

- [ ] **T27 — 取消、重试和待确认处理。**

  - 验收：超时、5xx、响应丢失和取消未受理时状态表达真实；待确认不能换幂等键盲目再付费；留存失败只重试留存；错误记录不含敏感原始数据。

- [ ] **T28 — 后台执行、重启恢复与限额。**
