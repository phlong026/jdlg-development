# 设计师工作台独立「AI视频」开发任务书与验收标准 Implementation Plan

> **For agentic workers:** 实施时使用已安装的 `subagent-driven-development` 或 `executing-plans` 技能逐项执行；本次只编写任务书，不启动代码实施。所有 `- [ ]` 均为未实施的计划任务。

**Goal:** 在甲地灵光设计师工作台单独新增「AI视频」模块，参考乡墅爆款短视频复刻系统的 AI 创作能力，完成从参考视频、人物素材、提示词到成片及内容使用的业务闭环。

**Architecture:** 新模块拥有独立入口、页面、草稿、任务与记录；由甲地灵光服务端统一处理身份、归属、计费和内容关联，再通过适配层调用创作服务。现有账号、上传、媒体播放、内容草稿等基础能力按适用性复用；既有 `pages/aivideo/aivideo` 不作为新增模块的承载页。

**Tech Stack:** 目标项目为微信小程序 WXML、SCSS/WXSS、TypeScript/JavaScript，Go/Gin、MySQL 及现有管理台 React/TypeScript；参考项目为 React/TypeScript、Python/FastAPI、PostgreSQL。跨服务复用方式在 T01 定案，不预设可以直接复制页面或共用两个系统的账号与账务。

**Spec:** 用户 2026-11-13 本次需求及补充「不是原来的AI视频创作功能，这是单独的新增功能」；具体范围、对标依据、任务与验收全部收录于本文。

**文档性质：** 开发任务书 V1，可用于范围评审、研发拆单和验收；不代表已经开发、联调或上线。以下数量是本次建议拆分的任务数，不是已完成数量，也不是人日估算。

## 一、需求边界与总任务数

### 1.1 这次新增什么

在「我的 → 设计师工作台」增加单独的「AI视频」入口，进入一个独立创作工作区，提供：

1. **视频拆解与复刻准备：** 参考视频 → 拆解分镜及口播 → 编辑分镜 → 人物/场景首帧准备 → 合成提示词 → 创建视频。
2. **长视频拆解：** 参考长视频 → 完整复刻提示词、逐句口播和全片摘要 → 复制、保存或继续创作。
3. **AI 视频生成：** 文生视频、首帧图生视频、首尾帧生成、图片/视频/音频混合参考生成。
4. **数字人口播：** 人物视频分身 + 已确认声音 + 口播文案，或人物视频分身 + 已有完整音频 → 口播成片。
5. **共用支撑：** 创作素材、人物档案、我的提示词、创作草稿、任务记录、费用与结果使用。

**人物置换属于第 1 条的首帧准备能力，可提供快捷入口，但不能把它解释为任意整段视频直接换脸。** 第 3 条是新工作区中的生成子功能，不是旧 `aivideo` 页改名或扩展。

### 1.2 本轮不自动纳入的范围

- 不建设整个爆款视频爬取/榜单/定时采集系统；允许使用本人上传或有合法选用权限的参考素材。
- 链接导入可评估复用现有内容导入能力；平台停用或无解析能力时提供上传入口，不承诺所有抖音、视频号、小红书链接均可解析。
- 不建设多平台自动发布、发布账号管理、播放量回收与独立运营数据看板。
- 不把人物照片自动等同于可用的口播视频分身；不把纯尾帧生成当作已开放能力。
- 不承诺长片原时长一键生成成片：长视频拆解产出提示词，生成时长仍受生成服务的独立能力限制。
- 不将生成成功自动解释为公开发布，也不自动改写项目笔记或替换用户已有正文。

## 三、建议页面与数据组织

### 3.1 页面层级

```text
我的 → 设计师工作台 → AI视频（新增独立入口）
  ├─ 创作首页：选择方式、继续草稿、最近任务
  ├─ 视频拆解：上传/选用 → 分镜 → 首帧置换 → 提示词 → 视频生成
```

小程序采用纵向步骤和二级页，不照搬桌面三栏布局。保持甲地灵光现有字体、米色与棕金色体系；空态、加载和失败态仍保留操作入口。新入口布局在 T02 设计，不在本任务书中擅自重排既有四个业务入口。

  - 验收：正常文件上传完成可选用；伪扩展名、损坏、越限文件在付费生成前被拒绝并说明原因；上传失败保留表单；中断不会错误显示上传成功或重复创建有效素材。

- [ ] **T07 — 从现有素材选择与返回。**
  - 任务：按图片/视频/音频选择有权使用的素材，支持搜索、分页、预览和取消；区分首帧、尾帧、混合参考及口播音频用途。
  - 验收：选择后只回填发起位置；取消不改原草稿；他人私密及无适用权限素材不可选；从素材页返回时创作参数和已选顺序保持。

- [ ] **T08 — 提示词编辑与「我的提示词」。**
  - 任务：支持手写、复制、命名保存、查询、导入和删除本人提示词；保留来源、生成模式及必要上下文；支持从分镜结果导入。
  - 验收：保存后退出重进可再次导入；覆盖现有内容需明确选择；空白和超长输入不能无提示截断；删除保存项不删除已提交任务的输入快照。

- [ ] **T09 — AI 优化与采用结果。**
  - 任务：提供普通画面描述优化、参考生成结构化提示词整理；显示原文与结果，允许编辑、采用、放弃；独立展示费用和执行状态。
  - 验收：未点采用不覆盖原稿；优化失败保留原文；更换账号、草稿或修订后不回填旧结果；无素材、错模式和已变化的引用有明确处理；人工合法提示词可按能力直接生成，优化不是无条件强制付费前置。

- [ ] **T10 — 素材编号、用途与引用一致性。**
  - 任务：按选择顺序显示引用编号，填写主体/空间/动作/音色等用途；增删、重排素材时重建引用并提示需要核对的提示词。
  - 验收：三类素材混合时编号与实际请求绑定一致；移除中间素材后不静默把原引用指向另一素材；恢复草稿发现素材失效时不能直接提交；音频用途说明不伪称已自动理解音轨内容。

### C. 视频拆解与人物置换：7 项

- [ ] **T11 — 参考短视频导入与门禁。**
  - 任务：上传或选用合法参考视频，可复用能力允许时的链接导入；前后端统一按 4–30 秒、200 MB 的目标门禁处理。参考后端当前采用固定用途常量，新模块在自己的能力契约中明确并统一下发限制。
  - 验收：4、15、16、30 秒均可完整导入；不足 4 秒、超过 30 秒及超过大小限制明确拒绝/引导长片入口；不存在前端 15 秒拦截、后端 30 秒放行的矛盾；链接不可用时可转上传。

- [ ] **T12 — 视频拆解任务与恢复。**
  - 任务：异步拆解画面、镜头、口播和首帧候选；展示排队/分析/完成/失败，支持继续查看及合法重试。
  - 验收：真实任务产生分镜和对应口播结果；无口播明确显示无可识别口播；离页/重启后可根据服务端任务继续；重复点击同次提交只有一个任务与一次费用。

- [ ] **T13 — 分镜表编辑、版本和保存。**
  - 任务：展示时间段、主体、空间、动作、镜头及口播等实际返回字段；支持编辑、调整顺序/时间、保存版本、复制及存为自定义提示词来源。
  - 验收：修改保存后再打开一致；起止时间和顺序错误有具体提示；旧版本可查看；新版本不会反向修改已提交生成任务；保存失败不丢人工编辑。

- [ ] **T14 — 原片画面选取与首帧确认。**
  - 任务：预览原视频、按时间定位/选择画面，展示原始首帧与时间点；允许上传或选用本人替代图作为后续生成输入。
  - 验收：所见画面与保存时间点一致；候选图加载失败可重试；采用图有明确已选状态；切换来源后旧首帧不能被误认为新来源已确认。

- [ ] **T15 — 人物/场景首帧置换。**
  - 任务：选择人物照片或场景形象，基于源画面生成候选首帧，支持预览、重新生成和采用；人物素材依赖 T30–T32。
  - 验收：候选与原图可核对，未点采用不改当前首帧；重新生成保留已采用图直至用户切换；付费操作先确认费用；不能把静态首帧置换宣传为完整视频换脸。

- [ ] **T16 — 口播整理与确认。**
  - 任务：展示原始提取文案，支持手动修改、AI 改写、确认终稿或确认无口播；保留文案版本和来源。
  - 验收：人工修改后旧确认状态失效；无口播路径能够继续；AI 结果未采用不覆盖终稿；进入数字人口播时带入的是所选终稿，不是原始转写。

- [ ] **T17 — 最终提示词合成与交接。**
  - 任务：合成分镜、选定首帧、文案及参数；显示上游一致性，支持编辑/保存并进入新模块内生成；冻结交接快照。
  - 验收：上游改变后旧合成标记失效且不得静默提交；交接带入正确首帧和提示词；16–30 秒源片遇到目标生成档位受限时明确让用户选合法时长，不默默截短或切换收费档；取消交接不创建付费任务。

### D. 长视频拆解：4 项

- [ ] **T18 — 长片上传与分流。**
  - 任务：提供长视频分析入口，目标接受 4–180 秒、600 MB 以内 MP4/MOV；默认将超过短片范围的来源引导至此，并支持用户主动选择全片分析。
  - 验收：边界内视频完整上传；不足 4 秒、超过 180 秒、超大小和不可识别媒体在建分析任务前拒绝；已上传来源的页面交接不要求无理由再次上传。

- [ ] **T19 — 长片分析、取消和持久恢复。**
  - 任务：异步提交全片分析，支持真实状态、已等待时长、取消请求、失败重试以及按服务端记录恢复；恢复能力为本次新增补齐。
  - 验收：关闭重进后仍可查在途/完成任务；取消请求受理前不显示已取消；外部任务是否停下与费用是否释放分别展示；超时待确认不自动重建付费任务。

- [ ] **T20 — 全片三类结果与保存。**
  - 任务：展示完整复刻提示词、带时间段的逐句口播、主题/风格/节奏/镜头/色调摘要；支持分别复制和持久保存。
  - 验收：三类产物独立呈现，缺项说明原因；没有口播不会伪造文案；历史结果可重新打开；不把它冒充逐镜头分镜表；复制操作有成功/失败反馈。

- [ ] **T21 — 长片结果继续创作。**
  - 任务：新增「使用提示词创建视频」「使用口播文案」交接；创建新草稿并保留长片来源关系，用户再选素材、参数和费用。
  - 验收：完整提示词/所选文案准确带入；长片 180 秒不自动变成 180 秒生成订单；仅点交接不扣生成费用；用户可返回长片结果而不丢新草稿；此项标为新增能力，不声称参考页已有。

### E. 新模块内的视频生成：8 项

- [ ] **T22 — 文生视频。**
  - 任务：只用画面描述创建视频，选择合法比例、时长、清晰度与数量；不要继承旧页面必须上传两张图的约束。
  - 验收：无首尾帧、无参考素材也能按已开放能力生成；空提示词拒绝；不向文生模式发送自动比例或残留图素材；费用确认中的参数与订单一致。

- [ ] **T23 — 首帧与首尾帧生成。**
  - 任务：支持仅首帧及首帧+尾帧；比例按目标服务实际规则处理，清楚显示实际提交值；纯尾帧保持关闭。
  - 验收：两种允许组合各完成一次真实生成；尾帧能力关闭时不显示可提交入口；仅尾帧在前后端均拒绝；替换图后参数和提示词核对状态同步更新。

- [ ] **T24 — 混合参考生成。**
  - 任务：图片、视频、音频混合选择，标注用途，生成结构化提示词并使用准确素材绑定提交；与首尾帧模式分开。
  - 验收：至少一项合法参考方可提交；三种类型分别与混合场景可运行；不允许同时偷偷带首尾帧；重复素材、失效素材和引用错位在付费调用前阻止。

- [ ] **T25 — 能力驱动的参数控件。**
  - 任务：从后端读取模式开关、清晰度、时长、比例和数量；对标 768P/2K、4–15 秒及受控 16–30 秒长档，显示实际可用组合。
  - 验收：能力加载、失败、关闭三种状态可区分；切 2K 后无法提交超过 15 秒；关闭长档后旧草稿不得照常提交 30 秒；数量以服务端上限为准，页面不擅自多建订单。

- [ ] **T26 — 素材及组合校验。**
  - 任务：按已验证能力统一执行图片≤8、视频≤3、音频≤3、总数≤12；视频/音频单条 2–15 秒，各类累计≤15 秒；复核类型、权限和引用。
  - 验收：覆盖每类刚好上限和超一项、2/15 秒及越界、累计 15 秒及超限；页面/恢复/服务端结果一致；篡改请求仍无法绕过；时长未知的素材先探测再计费提交。

- [ ] **T27 — 生成报价与确认。**
  - 任务：显示名称、模式、时长、清晰度、数量、预计/最高费用；取服务端报价并冻结输入快照，参数变更重新报价。
  - 验收：取消不扣费；报价过期、余额不足、档位关闭均不能误建单；价格含单价和计费数量/秒数，按实际乘积计算，不照搬参考页面中可能矛盾的倍数文案；返回的费用可与账务核对。

- [ ] **T28 — 批次提交与状态同步。**
  - 任务：幂等创建单条/多条生成批次，持久记录每条任务；展示排队、提交、生成、交付准备及终态，支持返回继续查询。
  - 验收：同次连续点击或响应丢失重试只有一个批次；重启后不靠页面内存继续；一个子任务失败不会把其他成功项抹掉；“状态待确认”不伪装成明确失败或再收费。

- [ ] **T29 — 生成页结果与继续创作。**
  - 任务：生成页就地显示预览、真实进度、逐条成功/失败，提供查看任务、改稿再生成及显式保存入口。
  - 验收：部分成功可分别播放成功项和查看失败原因；无百分比证据不显示假百分比；重新生成产生新草稿/任务且保留原结果；DIRECT 成功结果不因暂无归档媒体 ID 被误判失败。

### F. 人物与声音支撑：6 项

- [ ] **T30 — 本人人物档案。**
  - 任务：新增人物的姓名/备注、查询、选择、编辑、停用/删除；聚合照片、场景形象、视频分身和声音，按本人归属隔离。
  - 验收：人物可供拆解置换与口播选择；不能串用另一账号人物；停用不破坏已完成任务追溯；删除前说明依赖并保留必要订单/授权事实。

- [ ] **T31 — 人物照片与角色选择。**
  - 任务：上传、预览和选择有效人物照片，区分身份参考与生成图；标注选用状态，支持将照片用于首帧准备。
  - 验收：选择与生成输入一致；上传失败不产生假可用人物；旧照片撤销后新任务不能继续选用；照片不能直接显示为已就绪口播分身。

- [ ] **T32 — 场景形象与首帧素材。**
  - 任务：为人物创建/保存场景形象，可选用本人已有图；提供照片/形象到 T15 首帧置换的返回链路。
  - 验收：候选可预览、选择、保留版本；生成中不可当成功图提交；返回原创作时不丢源片、分镜和草稿；没有人物时可走本人场景素材路径，不强制无关的人像步骤。

- [ ] **T33 — 真人视频分身制作。**
  - 任务：上传已授权真人视频，检查目标服务要求，异步创建分身；展示准备中、可用、失败，支持名称管理与停用。
  - 验收：只有真实成功且归属匹配的分身可用于口播；不满足素材要求在调用前提示；失败保留原因及重试条件；分身准备不是口播成片，不混淆两个费用动作。

- [ ] **T34 — 声音克隆、试听与确认。**
  - 任务：上传授权声音样本，创建声音，支持试听、显式确认、命名和停用；语速等可选设置只开放供应商已验证能力。
  - 验收：未完成/未试听确认的声音不能用于文案驱动口播；修改声音设置后按规则重新确认；试听地址失效可刷新；创建与口播分别记录任务和费用。

- [ ] **T35 — 授权与人物资产关联。**
  - 任务：记录人物肖像、视频分身、声音使用授权及其版本/时间/使用范围；校验人物、分身、声音的关系，提供撤销/停用入口。
  - 验收：缺少必要授权不能开始克隆；不可将甲人物的分身静默配上乙人物未授权声音；撤销后阻止新任务使用，历史已完成任务仍可追溯；前台只展示业务所需信息。

### G. 数字人口播：5 项

- [ ] **T36 — 口播文案准备与终稿。**
  - 任务：手写/导入拆解文案或已有视频文案，提供适用的 AI 改写；可评估接现有内容文案工具，确认终稿后进入口播。
  - 验收：手写稿无需强制付费改写即可确认；改写不改变原业务笔记；确认后再修改必须重确认；超长文案明确拒绝或由用户拆分，不静默裁剪。

- [ ] **T37 — 文案驱动口播。**
  - 任务：选择人物、已就绪视频分身和已确认声音；预览终稿并设置字幕等已开放能力，保存草稿。
  - 验收：缺分身、声音、授权或终稿时准确指出缺项及准备入口；可在当前创作确认终稿；最终请求包含当前确认的文案和声音版本。

- [ ] **T38 — 已有完整音频驱动口播。**
  - 任务：选择人物视频分身及完整音频，允许上传或素材选择，预览音频并创建口播。
  - 验收：不要求选择克隆声音；不根据旧草稿文案再次生成配音；长度/类型/权限不满足时明确阻止；切回文案模式不丢原稿，返回后选用音频仍正确。

- [ ] **T39 — 口播报价、提交与恢复。**
  - 任务：按驱动模式和时长规则获取报价/预留，持久提交任务及不确定状态，支持离页、重启后继续查询。
  - 验收：两种模式分别成功建单；每条费用与对应任务可追溯；重复提交不重复计费；超时/响应丢失先查原任务；不能仅凭等待时间退款并重复创建外部任务。

- [ ] **T40 — 口播结果与字幕验证。**
  - 任务：展示成片、字幕状态和任务详情，提供下载、留存及按原输入另建草稿；失败保留文案、分身和声音选择。
  - 验收：真人测试素材的成片口型、声音、时长及字幕可人工核对；字幕开关与成片一致；音频驱动不出现旧文案内容；供应商失败不伪报生成完成。

### H. 任务记录与业务使用：5 项

- [ ] **T41 — 独立创作记录与筛选。**
  - 任务：统一列出本模块草稿、拆解、首帧、视频、克隆与口播任务；按类型、状态、关键词及时间分页查询；显示最近操作与可继续动作。
  - 验收：离开并重进可找到全部已提交任务；新模块记录默认不混入旧 AI 视频记录；空态、加载、无结果和失败态不同；批次与子任务数量口径一致。

- [ ] **T42 — 任务详情、来源和再创作。**
  - 任务：展示原输入快照、来源、分镜/提示词版本、参数、步骤结果、错误、费用及新旧尝试关系；支持按原输入创建新草稿。
  - 验收：原任务快照不能被当前编辑覆盖；明示重试是否另收费；跨账号改任务 ID 拒绝；相关素材被停用时仍能看必要历史信息但不能再提交非法引用。

- [ ] **T43 — 视频播放与下载。**
  - 任务：提供适用于小程序的授权播放、拖动、重新获取有效地址及下载/保存相册；区分直链交付和已归档结果。
  - 验收：真实设备可播放、拖动和下载；地址失效可按权限刷新；拒绝相册权限、网络失败和媒体失效有准确反馈；不把复制链接当成相册保存成功，也不以模拟播放替代真机下载证据。

- [ ] **T44 — 显式保存到创作素材。**
  - 任务：用户点击保存时归档或复用已留存媒体，创建本人可用素材，保留来源、封面与时长；归档中/失败/完成分别记录。
  - 验收：生成成功不强制等于已保存；保存后重进素材页可用；重复保存不产生重复有效素材；失败可续办且不重新收取生成费；只保存临时 URL 不算长期素材留存完成。

- [ ] **T45 — 用于内容与项目。**
  - 任务：将已留存视频作为内容草稿，或经用户选定插入有编辑权限的项目笔记；保留来源关系及现有草稿身份/修订校验。
  - 验收：只生成内容草稿或插入选定位置，不自动发布；原正文、封面及其他块不被覆盖；账号、笔记、草稿实例或修订变化时拒绝旧回填；已发布内容与私密项目资料仍按各自权限读取。

### I. 后台配置、费用与可靠性：5 项

- [ ] **T46 — 能力、供应商和运行配置。**
  - 任务：在现有后台增设新模块开关、服务适配、模式、限制、超时与并发配置；凭据仅保存在服务端安全配置中。
  - 验收：关闭某能力立即禁止新提交但仍可查询旧任务；缺配置展示真实未开放状态；前端/API响应/日志不返回密钥；跨系统适配的失败有可定位记录，界面不暴露无助于用户决策的内部信息。

- [ ] **T47 — 独立价格目录与报价规则。**
  - 任务：配置拆解、优化、首帧、分身、声音、视频、口播各适用收费项，明确按次/条/秒以及档位；对接既有灵石体系并区分新模块来源。
  - 验收：报价、确认弹窗、提交与账务同口径；改价只影响新报价；未配置/停用项目不能以零费误放行；完整成本与用户售价可核对；不直接复制参考系统的积分余额或套用旧视频 30 灵石价格。

- [ ] **T48 — 扣费、结算、释放与对账。**
  - 任务：持久保存收费快照、预留、成功结算和失败返还；按任务/步骤/批次关联账务，记录已交付待核对费用。
  - 验收：失败、取消、部分成功、重试和重复回执均不重复扣退；以创建时快照结算；有真实成功证据而账务未完时不丢结果；后台能从用户问题定位到单次任务及流水。

- [ ] **T49 — 取消、重试和待确认处理。**
  - 任务：统一业务错误类别，区分明确拒绝、已建单、提交待确认、生成失败与素材留存失败；提供相应查询、重试、取消或人工处理入口。
  - 验收：注入超时、5xx、响应丢失、取消未受理后状态表达真实；待确认期间不能换幂等键盲目再付费；保存素材失败只重试保存；历史失败原因可查且不包含敏感原始数据。

- [ ] **T50 — 后台执行、重启恢复与限额。**
  - 任务：持久化任务步骤及外部标识，实现后台认领/轮询/超时处理、并发限额和恢复；前端轮询只观察状态，不作为任务唯一驱动。
  - 验收：关小程序后任务继续；后端重启后在途任务可恢复查询；重复执行者不会重复创建付费请求或结算；切账号/离页停止无用轮询，迟到响应不覆盖新草稿；日志可按任务定位问题。

## 五、整体验收场景

每个场景均记录账号角色、素材、草稿/任务 ID、操作、预期、实际结果和证据。下表是验收场景，不额外计入 54 项开发任务。

| 场景 | 用户操作 | 通过标准 |
| --- | --- | --- |
| UAT-01 独立新增 | 从设计师工作台进入 AI视频，再从原路径进入旧视频功能 | 两条入口、页面、草稿与记录各自正确；新功能没有替代旧入口 |
| UAT-02 短片复刻 | 上传 16–30 秒参考片 → 拆解 → 编辑分镜 → 采用首帧 → 确认文案 → 合成 → 生成 | 不被旧 15 秒门禁误拦；所选首帧及最终提示词一致；合法输出时长明确；任务和费用可追溯 |
| UAT-03 上游变化 | 合成后改分镜、文案或首帧再提交 | 提醒原合成已失效；不会使用旧提示词和新图静默建单；重新合成后可继续 |
| UAT-04 长片分析 | 上传合法长片 → 离页/关闭重进 → 看摘要/口播/提示词 → 交接新草稿 | 任务可恢复，结果不丢；仅交接不扣生成费；不承诺生成原片同长成片 |
| UAT-05 四种生成输入 | 分别文生、首帧、首尾帧、混合参考真实生成 | 每种已开放输入均有可播放成片；纯尾帧关闭；参数、素材和计费匹配 |
| UAT-06 混合参考边界 | 选满数量/时长，再各加一项或改变顺序 | 刚好上限合法；超限拒绝且说明原因；引用顺序与实际素材一致 |
| UAT-07 人物与口播 | 创建授权分身/声音，确认终稿 → 文案驱动生成；再用已有音频生成 | 两条模式均出片；文案模式声音/字幕正确；音频模式不重复配音 |
| UAT-08 异常与资金 | 重复点提交、断网、响应丢失、明确失败、取消、部分成功 | 不重复扣费/退款；待确认不误导重试；成功结果保留，失败项有可处理路径 |
| UAT-09 结果使用 | 预览/拖动/下载 → 保存素材 → 建内容草稿或插入项目笔记 | 真机下载成功；素材长期可引用；原编辑内容保留；没有自动公开发布 |
| UAT-10 权限隔离 | 另一账号改任务/素材/人物 ID，使用无权限项目 | 服务端拒绝；原账号重新进入仍见自己正确内容；新旧记录均无跨账号泄漏 |
| UAT-11 恢复及后台 | 提交后关闭小程序，并在受控环境重启任务执行服务 | 服务端恢复在途查询且不重复创建付费任务；前端重新打开可跟踪同一任务 |
| UAT-12 发布/回滚 | 按发布包部署并执行新旧入口冒烟，再在隔离环境演练回滚 | 前后端版本匹配；新接口真实生效；既有工作台可用；回滚不删任务与收费事实 |
