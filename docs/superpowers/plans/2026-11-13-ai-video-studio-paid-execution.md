# AI 视频真实执行与灵石账务实施计划

沿用用户确认的 AI 视频页面和原任务书 `2026-11-13-designer-ai-video-taskbook.md`。本次补齐 T17–T18、T24–T29 的真实执行和收费链路。供应商为秘塔 H3；单价在独立后台配置，不在代码中写死。不得把隔离测试称为真实供应商或生产验收。

## 全局约束

- 保留独立 studio 命名空间、原视频功能及已确认界面；不复制参考系统账号、登录态或钱包。
- 共享钱包以 MySQL 为权威，同一事务写入扣减、批次、子任务、费用与用户流水。禁止 Redis 旧值异步覆盖钱包。
- 自动报价、点击直接生成；服务端冻结草稿修订与费用。报价只消费一次，换幂等键也不能重复扣同一报价；响应丢失可按原键找回。
- 未受理任务可以取消并释放；已受理仅查询；不确定提交绝不自动重发或误退款。秘塔未证明支持幂等提交/取消，不发明能力。
- 每条成片独立结算/退款，部分成功按原价快照分摊；分摊总和严格等于预留，重复回执不重复扣退。
- 任务在服务器执行，重启恢复使用持久步骤、外部标识和租约 CAS；持久 submitting 丢失回执进入待确认。
- 密钥只存在服务端环境，不输出、提交或回传；缺配置保持关闭。无生产部署/上传/发布授权。

### Task 1: 共享钱包持久化与计费事务

负责 `service/model/user_redis.go`、相关钱包测试和新的 `service/model/ai_video_studio_execution*.go`。先失败测试再实现：MySQL 原子条件扣减/增减、非负及溢出、无异步 Redis 回写；旧业务调用保持接口兼容。新 studio 在单个事务验证报价/草稿/配置/素材、幂等创建批次和子任务并预留灵石，事务失败不扣费。费用写入真实 `stone_records`。保存每条费用快照；终态事务独立结算或退款，严格幂等。MySQL 测试覆盖重复键/换键同报价、并发余额不足、回滚、部分成功、重启重复回执、与旧钱包并发。保留用户已有未跟踪目录。

### Task 2: 秘塔执行器与服务接口

负责 `service/aivideostudio`、服务 route/index 启停集成、执行 Store 的队列/租约方法。先测试后实现提交、查询、限并发、轮询退避、明确拒绝退款、生成失败退款、成功 DIRECT 成片结算；租约到期绝不重发提交。运营关闭禁止新单，已付费任务仍可查询并完成。素材用授权 HTTPS 签名地址。返回真实 readiness、可用档位、流水与取消入口；后台提供受审计的待确认处理（有外部标识先查询；明确未受理证据才能退款），不能人工填写假成片。覆盖提交超时、未知状态、重复 worker、重启、取消与成功/退款竞争。凭据与原始供应商响应不能泄露到日志。

### Task 3: 客户端闭环、审查与交付

负责小程序、管理台和文档。保留布局；补齐付费提交幂等恢复、详情前台轮询/离页停止、真实费用状态与取消反馈、后台待确认处理和收费口径。JS/TS 同源，报价失败和余额不足保留输入。更新配置示例、API、迁移/回滚说明与验证记录。执行完整相关测试、静态检查、依赖扫描、独立审查及隔离 MySQL 行为测试。确认当前环境凭据与真实调用条件，缺失时明确记录；不以假成片验收真实服务。提交本任务变更，分别报告本地/真实联调/上传/部署。
