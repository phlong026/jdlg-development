# 找设计师改版

按用户选定的四入口效果图实施：原创案例、乡墅私宅、庭院设计、灵感合集，米色/深棕配色，设计师名片与两列代表作品。

- 标题与底栏第三项统一为“找设计师”；保留已有底栏图标，通过原生文字覆盖图片中的旧标题。
- 乡墅/庭院入口切换现有设计师分类；原创案例进入模板广场场景，灵感合集进入公开灵感/案例精选。未配置对应分类时提示，不进入私密资料包或合集管理页。
- 代表作品默认按点赞数降序，同赞按发布时间降序、ID 降序；“最新发布”按发布时间、ID 降序。先从全部公开作品排序，再截取两张。切换只影响对应设计师的作品。
- 仅真实 approved 状态显示已认证。作品缺图显示“暂无封面”，不补假图/假数据。
- 咨询按钮携带 userId 和 consult=1 打开现有主页，资料加载成功后触发现有企微咨询流程。
- 服务地区尚无资料字段，本次显示“地区不限”，不提供无效城市筛选；综合排序沿用服务端原有设计师顺序。方向筛选保留现有逻辑。

## API 增量

`GET /api/v1/miniprogram/designers` 每个 list item 新增：

```json
{
  "work_previews": {
    "popular": [{"id": 1, "title": "作品名", "image": "https://example.com/work.jpg", "likes": 12, "tags": [], "publish_scope": "square"}],
    "latest": []
  }
}
```

两个数组各最多两项，按请求的 main_tab 筛选，复用现有公开作品权限边界。保留 representative_work 字段兼容旧端。前端连接旧服务端时回退显示一张代表作，完整双作品体验需要同时部署服务端。

## 验证和交付边界

新增行为测试覆盖排序切换、卡片隔离、真实认证、咨询身份、作品详情分流、公开专题衔接与原生 WXML 编译渲染。沿用原有失败保留列表的回归测试。

本次未新增依赖或数据库迁移；可以直接 revert 对应提交回滚。清理旧页面大量未使用样式，复用导航、登录门禁和咨询服务。列表继续使用已有分页，预览接口没有新增数据库查询；现有 buildDesignerCenterPayload 的逐设计师查询及全作品读取仍是后续性能优化点。

本机默认 CGO 的 Apple 芯片检测依赖初始化崩溃，后端使用 CGO_ENABLED=0 执行验证。当前微信开发者工具打开其他项目且模拟器启动失败，未将该状态当作甲地灵光的验收。尚未推送、上传小程序或部署服务端，真实角色/设备验收仍需在对应环境完成。
