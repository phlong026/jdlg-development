# 存储与下载费用优化：第一阶段

基线：`6feac3f`；分支：`fix/storage-cost-control-20261112`。这是本地代码改动，不是线上节费回执。

## 本次实现

1. 首页和模板广场继续预取列表缩略图、缓存详情数据，但不提前下载尚未打开详情的预览和原图。用户打开详情后正常加载，原下载权益不变。
2. 衍生图片在同一 namespace 内按原始图片字节摘要和完整生成规格复用；键包括编码版本、宽度、质量、变体名。COS HEAD 验证专用 metadata、JPEG与非空长度后才跳过上传。不同 namespace 不合并，旧URL保留；不会立即减少旧对象容量。
3. 后台 OSS 单删和批删必须先确认 COS 删除成功或对象不存在，再删除数据库记录。未配置、超时、权限和网络失败保留记录；数据库失败可重试。批删逐项返回回执，不再全量删除记录。
4. `ops/storage-audit/audit.py` 支持离线对象清单的前缀／类型／存储类别容量、最大对象、可靠 SHA256 重复候选和已知引用比对。报告始终只产生候选，不联网、不读取凭据、不执行删除。

## API 变化

- `DELETE /api/v1/management/oss/files/:id`：已无数据库记录视作幂等成功；COS失败保留记录并返回可重试错误，不向客户端暴露底层错误。
- `POST /api/v1/management/oss/files/batch`：最多100个唯一正整数ID，16KiB请求体上限；全部成功返回200；部分失败返回207及非零code，data含 `deleted_ids`、`already_missing_ids`、`failures`。每个 failure 包含ID与安全原因码；调用者应刷新成功项并保留失败项用于重试。
- 上述接口仍是管理员主动删除操作，不是无引用自动回收服务，也没有增加全站引用安全保证。

## 待完成的线上盘点与后续阶段

- 需要真实 COS 清单及数据库所有引用的同一时点导出。浏览器工具仍报告本地浏览器控制禁用，尚未读取腾讯云控制台；没有实际容量分布或节费金额证据。
- 私密项目附件、冻结版本、草稿、头像及异步任务不能仅按文件年龄删除。当前未建立完整引用计数，故不合并私有原始素材，也不改变历史对象引用。
- COS版本控制、非当前版本、失败分片、生命周期和地域配置未核实；未自动配置清理、转低频或CDN。分片清理应先确认最长有效续传窗口。
- 衍生图首次使用新键可能增加一套对象；历史旧衍生图须经引用盘点后回收，不能宣称本轮立即降低存储账单。重复内容仍需读取源图计算摘要，HEAD也产生请求；收益来自避免重复衍生存储/上传及减少不必要预览下载，不保证每次请求都更便宜。
