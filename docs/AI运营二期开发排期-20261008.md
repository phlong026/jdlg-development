# AI 运营二期开发排期（2026-10-08 制定）

> 前提：一期已上线并稳定运行 1~2 周（含一期补全：批量转工单 / 重新执行 / 视频队列 / 调序建议 / 供应商启停 / 周报导出）。
> 每个批次独立交付、可独立上线；批次内前后端一起发（部署硬约束）。

## 总览

| 批次 | 主题 | 建议周次 | 工作量 | 风险 |
|---|---|---|---|---|
| 1 | 数据地基：任务级成本落库 + 告警阈值可配置 | 第 1~2 周 | 5 人日 | 低（纯加列+新表，向后兼容） |
| 2 | 工具迭代闭环：草稿-发布分离 + 提示词版本 | 第 3~4 周 | 8 人日 | 中（改编辑流，运营需适应） |
| 3 | 执行管道可运营化：降级链在线调序 | 第 5~6 周 | 8 人日 + 2 人日回归 | **高**（动生成管道，需全链路回归） |
| 4 | 合规与增长：内容抽检 + 免费额度 | 第 7~8 周 | 9 人日 | 中（计费链路，需对账验证） |

## 批次 1：数据地基（第 1~2 周）✅ 本轮已随排期一并开发

**目标**：把"估算成本"升级为"任务级落库成本"，告警阈值从硬编码变为后台可调。

| # | 任务 | 说明 |
|---|---|---|
| 1a | `ai_tasks` 加 `api_cost`（分）/`provider_code` 列 | InitTable 追加 ALTER（幂等）；processor 成功结算时写入 = 模型单价 × 出图张数；历史数据不回填，从上线日起累计 |
| 1b | 成本口径自动切换 | 总览/定价页成本 = 落库值合计 + 无值行按估算补，页面标注口径切换时间 |
| 1c | `ai_ops_settings` 设置表（单行） | 失败率阈值 / 最小样本 / 检查间隔三参数；供应商管理页新增"告警设置"卡 |
| 1d | processor 读取配置 | 健康检查按配置间隔执行（默认 10 分钟），阈值实时生效 |

**验收**：新任务结算后 `api_cost` 有值；总览成本与任务表 SUM 一致；改阈值后下个周期生效；全部旧接口行为不变。
**回滚**：新列可空、新表独立，直接回退发布即可。

## 批次 2：工具迭代闭环（第 3~4 周）

**目标**：改提示词不再"保存即生效"，工具配置可版本化、可回滚、可对比。

| # | 任务 | 说明 |
|---|---|---|
| 2a | `ai_tool_versions` 版本表 | 每次保存生成草稿版本；发布动作落 published 快照 + 版本号 |
| 2b | 草稿态 | 编辑保存进草稿，列表标"有未发布修改"；小程序端始终读 published 快照 |
| 2c | 发布 diff + 回滚 | 发布前展示与线上版本的差异（提示词/风格卡片/图片）；一键回滚 = 用旧版本再发布 |
| 2d | 效果对比视图 | 版本切换前后 7 日成功率 / 用户重试率对比（数据源：任务表按时间切分） |

**验收**：编辑期间线上工具行为不变；发布留操作人；回滚后小程序端即刻恢复旧配置。
**风险与对策**：小程序端读快照需兼容无版本旧数据（回退读主表）；上线前用 2 个工具灰度一周。

## 批次 3：执行管道可运营化（第 5~6 周）

**目标**：降级顺序后台可调（现在硬编码在 processor），高危操作带护栏。

| # | 任务 | 说明 |
|---|---|---|
| 3a | 降级链 DB 化 | `ai_supplier_chain` 表（顺序/启停/模型），processor 启动加载 + 变更热加载 |
| 3b | 管理页拖拽调序 | 沿用一期"调序建议"，建议卡变"一键采纳"；二次确认 + 生效时间（立即/次日0点）+ 留痕 |
| 3c | 全链路回归 | 主模型成功 / 强制降级 / 全链失败退款 / ToAPIs 异步四条路径回归脚本 |

**验收**：调序不发版生效；强制降级路径按新顺序执行；回归脚本全绿。
**风险与对策**：这是唯一直接改生成管道的批次——必须先在测试环境跑 3c 回归脚本，生产发布选低峰，保留"恢复内置链路"一键回退。

## 批次 4：合规与增长（第 7~8 周）

**目标**：B 端输出的合规底线 + 获客抓手。

| # | 任务 | 说明 |
|---|---|---|
| 4a | 生成内容抽检 | 按比例（默认 2%，可配）随机把生成图抽入审核队列，复用灵感素材审核交互；结果图统一加水印（复用 video_watermark 能力） |
| 4b | 免费额度 | 新用户注册赠 N 次免费生成（默认 3 次，可配）；扣费优先级：免费额度 > 灵石；额度用尽引导充值 |
| 4c | 对账验证 | 免费额度消耗不产生灵石流水但记独立明细，日报可核 |

**验收**：抽检比例可调且审核结论回写；新用户首 N 次不扣灵石、流水可对账。
**风险与对策**：4b 动计费链路，先小额灰度（仅 ai_draw_single 场景）再放开。

## 里程碑与决策点

- **W2 末**：批次 1 上线 → 决策点：成本落库数据跑一周后，复核模型单价表是否需要校准。
- **W4 末**：批次 2 上线 → 决策点：运营是否需要"定时发布"（当前即时发布）。
- **W6 末**：批次 3 上线 → 决策点：降级链是否进一步做"按成本路由"（单价低的优先，属批次 3 扩展）。
- **W8 末**：批次 4 上线 → 二期收官，评估三期（多品牌租户隔离的 AI 配置）。
