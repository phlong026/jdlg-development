## 三、后端成果

**新增数据库对象（部署建表自动完成，均为幂等 CREATE IF NOT EXISTS / 可空 ALTER）**

| 对象 | 用途 |
|---|---|
| `ai_pricing_versions` | 调价留痕（操作人/旧值/新值/备注），回滚=用旧值再调一次 |
| `ai_ops_settings`（单行） | 告警阈值：失败率/最小样本/检查间隔，带安全范围护栏 |
| `ai_tool_versions` | 工具版本链（draft/published/archived，每工具一条草稿） |
| `ai_tasks` + `provider_code`/`api_cost`(分) 两列 | 任务级成本落库，历史留 NULL 由估算补 |

**新增/改造接口**

- `GET /management/ai/overview` —— 总览聚合（KPI/趋势/场景/供应商/链路建议/告警/队列计数）
- `GET|PUT /management/ai/ops-settings` —— 告警设置
- `GET /management/ai/pricing/ops`、`GET /management/ai/pricing/versions` —— 定价运营视角与历史
- `POST /management/ai/tasks/batch-support-tickets`（批量转单）、`POST /management/ai/tasks/:id/retry`（重试，拒绝造价文档）
- 图片/视频任务列表支持 `queue` 参数并返回 `queues` 计数；列表带 `refunded_stones`
- 工具：`POST /:id/publish`、`GET /:id/diff`、`GET /:id/versions`（含效果对比）、`POST /:id/rollback`；PUT 保存改为写草稿（版本表不可用时自动降级为旧行为）

**执行链路增强（processor）**

- 供应商失败率告警自动建工单：近 1 小时失败率超阈值且样本足够 → 高优工单，未关闭去重，工单中心与总览页可达
- 告警阈值从设置表实时读取（1 分钟基础 tick，读取失败回退默认值绝不停摆）
- 任务成功结算时落库执行供应商与成本（单价表唯一来源 `model.AIModelUnitCostYuan`）

**成本口径（混合）**：已落库任务用精确值（api_cost），历史任务按模型单价估算；KPI 显示"X% 来自任务级落库"，随新任务积累自动趋近精确。

## 五、运营须知（行为变更 4 点）

1. **AI 配置入口变了**：定价调整和供应商管理在「AI 运营 → 定价与供应商」；旧页仅 ⌘K 可达。
2. **任务中心落地即"失败待处理"**：先处理异常，再看全量（Tab 切换）。
3. **工具保存≠生效**：保存进草稿，点"发布"（看 diff 确认）才上线；可随时回滚。
4. **调价需二次确认且自动留痕**：谁能改、从多少改到多少，历史可查、可回滚。
