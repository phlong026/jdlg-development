# AI 页面先浏览、账号操作再登录

本次承接11月11日工作台和视频播放修复，仅调整 AI 访问边界，不改变页面布局。原三个匿名发现页之外，开放八个 AI/测算表单。AI 生成、优化、上传和个人结果/历史仍须有效账号，头像昵称不再作为 AI 使用的前置条件；对外报告、方案、资料包和项目笔记分享保持完整资料门禁。

## 修复内容

- 页面门禁区分公开表单、账号页、完整资料页。AI 登录取消后留在表单，匿名登录升级保留输入，已登录账号切换重新初始化账号数据。
- 个人草稿、视频活跃任务和测算结果按账号隔离；不读取无法确认归属的旧全局缓存。
- 后端仅公开价格和已发布工具的精确 GET 路径，AI 账号接口保持原鉴权、所有者、封禁和计费检查。
- 公共价格限定查询场景及数量，仅输出价格与视频时长范围；公开工具不输出内部提示规则与模型专用引用图。管理端完整配置继续保留。
- 修复价格缓存漏存额外配置：使用独立版本化内部 DTO，旧缓存按需回源自愈，不将内部配置加入公共模型 JSON。
- 既有匿名跟踪扩展到八个公开表单；私人生成历史、任务进度和结果仍不采集访问事件，不记录提示词或私人输入。

接口及状态码见[访问契约](../../api/ai-preview-access.md)，审核文本见[审核说明候选](审核说明.md)。

## 验证与交付边界

执行记录需分别保存本地测试、代码提交、后端部署、小程序上传/体验版与微信审核状态。不得把部署成功写为审核通过。原生模拟器及生产 API 验证不代替真实手机、弱网和付费生成验收。

本轮不修改数据库结构、环境变量或代理配置。程序替换前核对当前运行二进制，并由既有发布器备份环境、启动参数和旧二进制。回滚需恢复上一程序与对应小程序版本；价格缓存为可重建缓存，版本不匹配时由新程序回源。

专用旧 AI handler 的账单写入/退款事务一致性为已有风险，本轮不扩展重构；本轮没有执行会扣费的真实生成任务。
