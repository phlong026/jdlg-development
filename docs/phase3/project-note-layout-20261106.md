# 项目笔记排版与易用性整改

## 修改前计划

保留项目笔记的私密协作、固定版本、分享和反馈语义。先运行既有回归，并为保存前预览、媒体完整性、预览返回保留输入、键盘状态补充失败测试，再修改。

1. 编辑页按项目上下文、标题与正文、素材、主要操作组织，保存/预览始终容易找到，键盘打开时避免底部操作遮挡输入。
2. 提供无须保存的草稿预览，使用已有私有下载接口与正文渲染函数；预览不生成版本、不发布、不创建分享。网络失败保持输入，可重试或返回编辑。
3. 复用同一正文模板和样式展示草稿预览、设计师版本及受邀阅读页，删除重复渲染，保证段落、标题、列表、图片、视频、图注一致。
4. 素材显示缩略图或可识别占位，版本、反馈和处理操作使用正常文档流，避免长文字被浮动按钮遮挡。
5. 运行小程序回归、类型/原生编译及依赖与凭据扫描；检查原生模拟器短文、长文、媒体、错误和版本状态。真实接口/真机未验证部分单独说明。

不新增依赖，不改后端接口，不自动转换已有笔记正文。按逻辑变更提交，保留可直接revert的回退路径。

## 实现结果

- 编辑页重新分为项目上下文、标题正文、方案素材、固定版本和历史版本；保存/预览固定在底部，键盘出现时隐藏底部操作，AI辅助位于正文标题附近。
- 保存前即可完整预览。返回编辑保留输入，失败可重试，旧账号或迟到响应不能恢复之前的私密正文。预览不保存、不生成版本、不创建分享。
- 草稿预览、设计师固定版本、单方案受邀阅读、资料包方案阅读共用主包中的正文模板，避免跨分包引用资源。删除三处重复的正文排版。
- 标题、段落、引用、列表、图注统一排版；反馈回复按钮进入正常文档流，长反馈不再与浮动按钮重叠。
- 单图按自然比例完整展示，可点开原图；连续多图归为原生swiper图集，可左右滑动，显示当前序号/总数和当前图注。图片之间有文字或视频时保留分组边界，不重排原文。
- 图集使用稳定高度、aspectFit完整显示横竖混合图片；单图使用widthFix，不因视频限高规则截断长图。
- 视频容器保持源宽高比：16:9在屏高允许时铺满正文宽，9:16限高并居中，方形和超宽同样计算。上限为当前视窗高度62%，这是本项目的阅读页设计值，不是平台规范。
- 视频元数据到达后可修正缺失的尺寸；窗口尺寸变化后重新计算。原始媒体宽高、固定版本正文和保存payload保持原值。
- PDF/Office等任意附件不在本轮扩展；资料包继续按已有方案业务展示。

等比视频容器参考[腾讯云点播FAQ](https://mc.qcloudimg.com/static/qc_doc/19d1bd7450a6ed41ae20648e338e3267/doc-Video%2Bon%2BDemand-FAQ.pdf)中的播放器与源视频比例一致原则；图片点开查看原图参考[飞书图片说明](https://www.feishu.cn/hc/zh-CN/articles/172132728301-在文档中插入图片)。具体限高和图集分组方式按本项目客户阅读场景确定。
