# 本轮接口与流程兼容说明

## 项目创建后的客户关联

`PATCH /api/v1/miniprogram/project-notes/projects/:id`

保留`expected_revision`乐观锁。增加可选`customer_ref`：不提供则保留原关联，空串解除关联，非空值绑定或更换。非空值复用创建项目时的本人可信客户验证；无权限、非法引用或验证器不可用均拒绝。其他项目字段不因客户变更被清除，不使用`crm_id`替代客户引用。原POST创建接口及客户详情深链预选保持兼容，无新增表和迁移。

完整私密笔记接口与权限规则见[私密项目笔记](../private-project-notes.md)。

## 指定素材的本人访客

- `GET /api/v1/miniprogram/tracking/my-visitors`
- `GET /api/v1/miniprogram/tracking/my-visitors/entries?visitor=<visitor_key>`

在原日期、快照、分页、访客和权限参数上，可提供`route_key`、`content_id`、`content_version`。版本必须与素材ID一起提供。筛选在服务端聚合和分页之前执行，采用与`my-content-stats`相同的合集归组键；同一访客跨本人分享去重，浏览次数仍累加。指定素材时，不加入仅有关联项目但未浏览该素材的客户。

素材身份属于分页范围，不能把另一素材或另一权限范围的游标拿来继续翻页。由无素材的父统计窗口钻取时，仅接受同actor、完整权限、归属、快照及创建时间窗口的父游标，随后服务端将current_cursor与next_cursor重签为当前素材范围；前端用重签current_cursor继续详情和翻页。启用created_window时游标签名额外绑定Start/End，默认关闭时保持旧签名兼容。空`route_key`不改变旧无素材范围的签名序列化。意向仍按完整规则窗口计算，不把某一素材的展示事实误当全部意向事实。原本人分享数量和时间窗口上限继续适用，不能将有界窗口显示成全部历史。

素材列表主入口改为素材访客，分享批次为次入口。列表到客户详情持续传递素材、版本、路由、日期、快照及分享范围；客户身份与CRM承接仍保留现有权限和真实状态语义。

## 受控的固定版本管理预览

`GET /api/v1/miniprogram/workbench/contents/:id/versions/:version`

使用既有工作台登录认证和权限范围；要求有效管理权限、合法素材ID、正整数版本及授权归属。只返回所选已存储固定版本，不返回最新草稿，不为普通公共读接口增加免授权参数。

`contentreader`的管理预览只能从此鉴权接口载入。该模式不解析公共归因、不初始化浏览或播放器统计、不预热分享，也不展示分享/评论/互动操作。普通客户阅读继续走原公共读接口和原计量流程。伪造`management_preview=1`不会获得私有内容，缺少权限的请求会被服务端拒绝。

普通已发布内容提供精确版本入口。合集访客筛选复用合集身份；不向没有合法管理预览接口的合集目录显示假预览按钮，合集管理仍从现有管理入口进入。

## 保存、发布与发送

- 公开内容“保存草稿”只保存；“预览”可选。直接“发布”内部执行保存最新稿、申请该修订的`preview_token`、发布。服务端屏障、修订校验和幂等键保留。
- 私密项目“保存笔记”只保存，不冻结版本、不创建分享。“发给客户”才执行必要保存、匹配固定版本、取得有效分享、打开原客户预览页；用户仍自行选择微信联系人。
- 保存、生成、分享的迟到响应均核对账号和目标草稿。请求期间的新改动保持未保存，不能误标已发布或自动跳页吞稿。
- 冻结不是幂等写入。结果不明时保留检查点，先读回比对完整固定快照，不盲目再次冻结。分享凭证仅首次可得，缺失时明确恢复，不暗中撤销旧分享。
