# 内容媒体自适应边界与验收

## 展示规则

- 图片和视频的展示框始终保持素材宽高比，不用固定最小高度把超宽素材撑成带边画框。
- 图集容器跟随当前页的实际高度；滑动到不同比例图片时重建展示模型，不以整个图集的最大高度预留空白。
- 正常比例素材在可用宽度内完整展示。超高素材受视口限高时等比缩小宽度并居中，不拉伸，不在媒体元素内填黑边。
- 图片和视频元数据未到时分别以 `3:4` 和 `16:9` 回退；图片 `load` 或视频 `loadedmetadata` 返回真实宽高后，阅读页与编辑预览重建同一展示模型。
- 本轮不改视频 URL、原生播放控件、Range 请求、保护媒体授权和播放跟踪事件。

## 视觉夹具矩阵

| 视口 | 素材 | 验收点 |
| --- | --- | --- |
| 390×844 | 1920×1080 横图／横视频 | 宽度用满可用区，展示框为 16:9，无黑边 |
| 390×844 | 1080×1920 竖图／竖视频 | 限高后等比居中，不裁切正文素材 |
| 390×844 | 4000×300 超宽图 | 不强制最小高度，不出现上下填充带 |
| 390×844 | 300×4000 超高图 | 受限时同时收窄宽度，宽高比不变 |
| 844×390 | 1920×1080 横图 | 重建后高度不超过当前视口的 68% |
| 390×844 | 视频先无宽高、后返回 1080×1920 | 先用 16:9，元数据到达后切换为 9:16 |

自动化回归使用同一矩阵校验计算几何和模板绑定。原生截图应在合入后生成页内嵌模板，再以上述六个场景各取图一张；截图只证明样例布局，不代替真机私有媒体、播放和横竖屏验收。
