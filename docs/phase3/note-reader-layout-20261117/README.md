# 项目入口与笔记阅读布局

## 页面修改

- 项目笔记页：保留左侧状态，把项目资料、未关联/已关联客户收进同一右侧操作组，去掉单独的关联客户行。原事件与权限保持一致。原生复核发现微信按钮默认宽度撑开，已使用内容宽度覆盖，复核操作组宽149px。
- 笔记阅读页：作者头像和名称前置，右侧保留“更多”；去掉单独占一行的分享和三个点。标准分享继续使用微信胶囊菜单，“更多”内另留分享按钮及编辑、删除、导出等原业务操作。
- 图文图片按阅读视口排布，标题调整为20px、600字重，正文和时间分层；作者不在文末重复出现。保留视频现有播放与操作流程。
- 时间：RFC3339/Nano按设备本地时区显示到分钟，例如上海2026-11-09T05:25:19.153277048Z显示2026-11-09 13:25。纯日期保持原日期，空/非法值隐藏，不显示原始ISO串。
- 评论区：刷新按钮固定靠右，空态收短为“暂无评论”；底部评论、点赞、收藏入口保留。“更多”高于底部操作栏并限制高度，避免小屏末项被遮挡。

## 微信菜单边界

微信系统胶囊不能注册编辑、删除、导出等任意业务菜单，不能将自定义业务菜单直接并入其中。以下官方文档已核对：

- https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.showShareMenu.html
- https://developers.weixin.qq.com/miniprogram/dev/reference/api/Page.html#onshareappmessageobject-object
- https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/page.html
