## 页面结果

[页面截图总览](页面截图总览.html) 展示六个页面以及编辑器两种模式和滚动状态。

- 保持米白、深棕、棕金配色，以双屏确认稿为参考；执行用户最新覆盖：等大的 **9:16** 首尾槽、直接生成、精简多余文字。
- 参考素材按本轮补充改为 **16:9 横向空白＋号占位**，选中图片/视频后的预览和继续添加卡片同比例；去掉重复的“+添加”文字。空态实测 `368×207`，已选预览/添加卡片实测约 `180×101`（像素取整）。76 项相关回归通过，原生验证加号打开选择页并回填素材；见 `reference-placeholder-review.json`。
- 首尾槽原生实测均为 `180×320` CSS 像素。占位比例不强制改写视频生成参数；图生仍按实际首帧自适应。
- 修复提示词名称、素材搜索的占位字裁切：单行输入框使用明确高度和水平内边距，实测高度 47 CSS 像素。
- 六页统一导航、字体、间距和按钮；去掉重复标题、说明段落和未开放的 AI 润色入口。只选图片时隐藏冗余分类和不可用上传栏；保留可用操作、费用、错误和重试。
- 图片支持原图预览；视频可预览；音频区分加载/播放/停止，只有真实 `onPlay` 才显示播放状态。切页、删素材、换账号、列表替换会停止播放器；失败或加载超时可重试。

截图来自微信开发者工具中的可丢弃离线项目，只复制实际页面和组件，API 与报价为本地夹具。36 灵石是示例值。本地 MP3 测试音和视频由 ffmpeg 生成，不使用 AI 服务。模拟事件有用户手势限制，不能将按钮触发等同于真机听感验收。

## 前后端修复

- 首尾帧入口锁定图片，分类、上传、选择与编辑器回填均检查媒体类型。
- 首页返回刷新；草稿/任务局部读取失败独立提示；列表重试不再把点击事件误判为下一页。
- 提示词支持分页和 7000 字；列表按稳定 ID 去重；批次名称来自不可变输入快照。
- 六页支持资料守卫的账号热重载；保存、上传、报价、提交恢复、播放、留存、采用和弹窗均隔离旧账号或旧页面操作。上传/下载额外校验操作身份。
- 参考素材上限的显式零值生效；报价前和提交构建共用最终提示词校验，包含素材用途及合并后的 7000 字上限。
- 新配置和运行缺省全局并发为 **3**；既有显式配置保留。待确认任务仍占并发，不放松重复付费保护。
- 小程序能力、报价、首次批次和管理台复用模式/媒体依赖/真实价格档位门禁；幂等重放和历史查询继续开放。
- 管理台展示逐模式就绪和缺项，保存时剥离只读状态，数值范围与服务端一致。
- worker 与建表日志增加安全的操作、任务和错误类别信息；不输出供应商原始响应、提示词或密钥。
- 供应商暂时不可查询时，已存的安全 HTTPS 成片直链可以继续尝试；不安全地址不降级放行。
- 留存 **50MB** 硬上限保持，超限明确返回 413；保存和采用不伪报成功。是否提高上限需另行评估，未擅自改变存储成本策略。
