# AI 视频修复与页面对照计划

范围：新版 `aivideostudio` 小程序、对应后端及管理台；保持旧 `aivideo` 功能。基线 `c4df672`。禁止部署、上传发布和付费供应商调用。

## 验收清单

- 首尾帧仅可选择图片；图片完整预览、视频预览、音频试听均可操作，离页停止播放。
- 首页返回刷新、创作记录名称、提示词分页与长度保持正确；账号切换及迟到响应不串数据。
- 后台参考素材零上限生效；完整提示词在报价前校验；全局并发默认 3，保留显式配置。
- 管理台按模式显示真实依赖与价格就绪状态；日志包含安全的操作和任务上下文。
- 根据 `ai-video-studio-20261113/design-approved.png` 对照生成页。用户本轮最新要求：首尾槽保持等大，改为 9:16 竖版；保留直接生成。去掉重复标题、说明段落及未开放按钮，保留必要状态、价格和错误提示。占位比例不改写服务端实际输出参数。
- 素材、提示词、记录、详情页沿用同一米白/深棕/棕金样式，保留必要功能。
- 对 50MB 留存、供应商暂时不可用和待确认任务占用并发的边界逐项核对，避免以隐藏问题或放松账务保护代替修复。

## 顺序和证据

1. 基线检查：小程序现有相关测试 48/48 通过。
2. 后端、前端行为、管理台各自先写复现测试，再实施。
3. 主代理对照确认稿整理 WXML/WXSS，使用离线素材运行原生预览。
4. 完整相关测试、隔离 MySQL、静态检查、依赖扫描、独立审查；保存截图和验证结果。
5. 检查可回退性后本地提交，不推送、不合并、不部署。

视觉对照采用实际截图逐项比较。当前没有安装 `visual-verdict` 技能，保存等价 JSON 记录，不伪造评分或真机验收。
