## 发布与回退边界

- 仅扩展现有 JSON 字段，没有新增表结构、配置、依赖、数据库迁移或钱包切换。现网 `55f836d` 已有的钱包与 AI 执行实现不属于本轮变更。
- 最终合并源码在干净工作树通过受保护构建器注入现有认证源；认证材料不进入 Git 或普通发布包。后端与管理台同源构建，切换前保留二进制、运行环境、配置和完整后台备份。
- 后端使用现有 `binary_release.py` 的 prepare / activate / rollback；管理台先部署资源、最后切入口，保留旧资源。部署后核对进程实际 ELF、后台清单和公网状态。
- `creator_id` 存在已有 content / version JSON 内，旧程序可忽略读取；但旧程序重新编辑、撤回或删除内容行会丢弃这个新增字段。因此代码回退并非作者元数据的无损回退。回退前先停止内容写入并在私有目录备份当前 content / version 记录及创建者对应关系；不得用上线前快照覆盖上线后的业务内容。其他内容、版本和媒体记录不因回退被删除。
- 秘塔、服务号、豆一豆和元宝的凭据配置、真实付费生成与真实通知投递不在本轮新增范围；不以本轮发布声称这些业务已完成联调。
