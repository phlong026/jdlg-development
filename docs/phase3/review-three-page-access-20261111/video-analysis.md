# 视频号转存、分享播放与 50MiB 限制

## 已确认的链路差异

用户提供的既有实测说明已导入视频使用自有 `/tracking/media/<id>`，本轮代码也确认导入会转存到自有存储。不能把已入库视频的播放失败一律解释为视频号外链过期。

| 问题 | 当前代码 | 结论与修复方向 |
|---|---|---|
| Range 请求返回整段 200 | `service/contentstorage/stream.go` 和 `route/content_media_storage.go` 已处理单段范围、206、Content-Range、416，并有通过的回归 | 用户旧实测成立于当时请求；当前线上是否已修复须用同一真实媒体重新探测。不能把当前单测当成公网 nginx/部署验收 |
| 公开内容视频 | `contentreader` 优先获取短时签名地址交给播放器 | 与项目接收页不同，不应混为同一播放实现 |
| 项目笔记/附件视频分享 | `projectnoteview.ts:115` 对视频也调用 `downloadSharedProjectNoteMedia`；`phase3-api.ts:157` 使用 `wx.downloadFile`、超时 15000ms，并等待媒体下载后组装正文 | 仍是全量下载，不会因为服务端支持 Range 就自动成为按需播放；17MiB 在弱网下也可能超过 15 秒 |
| 草稿 asset.url 公开路由 404 | 导入/上传资产仍带 tracking media URL，编辑器和私有项目阅读另走授权下载路由 | 草稿不应开放公开路由；应按草稿管理权限、公开发布权限、项目分享权限分别返回可用的预览/播放能力，避免直接跨场景复用 asset.url |
| 导入重试复用临时链接快照 | `contentimport/store.go` 的 Retry 复用 `resolution_json`，过期媒体进入 blocked | 仍需在来源过期时有界重新解析，保留已转存素材和去重键，避免无限重试 |
| 视频号/外链导入大小 | `route/content_import_media.go:45-47` 视频 `50 << 20`（52,428,800 字节） | 这是本系统导入上限，不是视频号或微信统一的 50MB 限制 |
| 项目视频上传大小 | 项目笔记视频 500MiB，图片 20MiB；另有可恢复分片上传 | 500MiB 上传能力不代表视频号导入或接收端播放也支持同样大小 |

## 能否去除 50MiB

可以调整，但当前导入器使用 `io.ReadAll(io.LimitReader(..., max+1))`，将完整视频读入内存。只把数值改到 500MiB 或无限制，会放大内存、并发、磁盘和超时风险。

建议保留明确资源配额，将视频导入改为后台任务流式写临时文件、校验格式/大小/摘要后流式写 COS，再将产品上限按实际容量提高，例如与项目上传的 500MiB 对齐。同步调整任务超时、并发配额、失败清理和前端错误提示。

微信 `wx.downloadFile` 官方文档当前写明单次最大 200MB。因此接收端仍走全量 downloadFile 时，即使后端允许 500MiB，也无法保证大视频能打开。应将播放器与“下载原文件”分开实现。[官方 wx.downloadFile 文档](https://developers.weixin.qq.com/miniprogram/dev/api/network/download/wx.downloadFile.html)

## 推荐顺序

1. 先把项目分享页的视频改为原生播放器直连短时授权的自有媒体流，正文和封面先显示；授权绑定分享及素材，逐请求保留权限/撤销校验。保存原文件另用下载流程。
2. 用真实项目分享验证 `Range: bytes=0-1023` 返回 206、1024 字节和准确 Content-Range；同时测拖动、弱网、分享撤销和失效签名刷新。只有发现 nginx 丢弃 Range 时才改代理配置。
3. 区分草稿管理预览、发布内容播放、私有项目分享三个授权入口，不把草稿发布成公开素材来掩盖 404。
4. 来源过期有界重新解析，再做大文件流式导入和可理解的失败提示。

本轮按用户要求只分析视频问题，未改播放、导入、nginx 或数据库。上述播放与导入改造需要前后端配套；首页审核整改本身不需要后端部署。

## 同类产品可借鉴的方案

未指定同行产品或取得其播放请求，不能断言某家竞品的内部架构。腾讯云官方支持的成熟组合是：授权内容异步转存、自有私有存储、短时播放地址、原生播放器范围读取；弱网较长视频再配合低码率转码或自适应码流。

- [COS Range 下载](https://cloud.tencent.com/document/product/436/14115)：播放按需读取字节范围。
- [COS 预签名 URL](https://intl.cloud.tencent.com/zh/document/product/436/45243)：临时授权私有对象，按播放会话刷新。
- [COS 分块上传](https://cloud.tencent.com/document/product/436/14112)：用于大文件与失败块重传。
- [VOD 媒体处理模板](https://cloud.tencent.com/document/product/266/33818)：用于码率与自适应流配置。

对本项目优先复用现有 COS、鉴权和 Range 输出，补齐私有项目分享的短时播放能力。视频号临时源链接只参与导入，分享给客户的播放链接由本系统签发。授权范围与用户跟踪分别管理：签名令牌负责播放权限，访问/播放事件负责追踪，两者都保留。
