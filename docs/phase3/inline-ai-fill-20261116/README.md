# 内容编辑页 AI 直接生成与回填

2026-11-16，基于主分支 `5c410aa`，追加到已部署的 PR #53 与小程序 8.0.10 之后。

## 用户操作

图文笔记、视频笔记及文章编辑页点击「AI辅助」，在当前页生成介绍或正文并直接回填，不再跳转独立文案表单。用户可以继续编辑、恢复生成前内容，再自行保存或发布；生成本身不保存、不发布。

未填写主题或文字要点时，在当前页提示补充。只使用标题、已有文字、素材短注释与数量；文字模型不能看到媒体画面，不传私密媒体路径或编造视觉事实。

## 修改部位

| 部位 | 调整 |
| --- | --- |
| `pages/contentedit/contentedit.{ts,js,wxml,wxss}` | 原页流式回填、生成状态、恢复原文；保留文章预览及保存/发布入口 |
| `utils/writing-policy.{ts,js}` | 复用既有事实约束，为图文及视频生成简短介绍 |
| `utils/ai-stream.{ts,js}` | 结束时接收无换行尾帧；终态只回调一次；支持四字节 UTF-8 与跨块字符 |
| `components/tdesign-miniprogram/icon/icon.js` | 纳入独立图标运行库修复，避免缺少 tslib 导致页面无法加载 |
| 对应测试 | 原页生成、恢复、错误、账户与草稿隔离、人工编辑、文章结构保持及 SSE 字符解码回归 |

保留主分支已有的作者信息、项目封面、权限失效清空、项目视频返回、精简 AI 面板和四个工作台入口。本次没有后端、管理后台、数据库、依赖或运营开关变更。

## 验收与发布边界

- 点击 AI 不发生页面跳转，结果可编辑；失败、空结果、余额不足保留生成前内容。
- 生成中不能保存、预览、发布、置顶、撤回或删除；人工编辑会停止生成并隔离迟到结果。
- 换账户、归属、草稿或页面离开后，旧响应不能覆盖新内容；冲突状态要求重新进入编辑页。
- 文章既有标题、列表、引用及媒体顺序保持，只填充空段落或追加一段正文。
- 全量测试、类型诊断基线、独立审查、CI、合并、官方上传与体验版指向分别留证。手机输入、相册和真实供应商生成仍需按实际完成情况记录。

本次只更新小程序。服务器继续使用 PR #53 已部署的兼容后端和管理后台，核对部署哈希与公网状态后保留现网进程；无需为前端补丁重启服务。若回退，重新上传此前已验证版本；源码可逆序 revert 本次逻辑提交。不会回滚已保存或已发布的用户内容。
