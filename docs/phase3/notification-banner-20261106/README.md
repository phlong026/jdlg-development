## 修复行为

- 横幅按微信胶囊底部加 8px 定位，固定浮层不推动首页画布；关闭区域至少 44×44px。
- 点击叉号立即关闭。同一登录会话在本次小程序运行期间不再自动弹出，包括返回首页和重新创建首页；新消息也保留在消息中心。重新启动小程序或更换登录会话后可再次提醒。
