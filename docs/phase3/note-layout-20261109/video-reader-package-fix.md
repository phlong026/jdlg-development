# 视频阅读页只剩来源与操作栏

## 证据与修复

用户截图的视频阅读页没有视频、标题、正文，仅显示来源、咨询卡片和底部操作。页面这三项正文全部由 `content-presentation` 模板输出，外围卡片独立输出。

阅读页属于分包。原生 wcc 只编译页面、未同时注册主包裸 WXML 模板时，可重复得到相同空白形态，并报告模板不存在；原有测试显式把共享模板加入同一次编译，未覆盖依赖缺失。完整开发者工具编译仍可正常显示，因此目前证据定位的是缺失模板的故障条件，尚未读取用户体验版的实际编译产物以确认具体丢失阶段。

构建时将共享模板定义内联到阅读页和编辑预览页面，取消运行时跨目录导入模板。共享维护源和页面事件处理函数保持原样，无需增加组件事件转发、接口或数据库变更。每页增加约 8KB WXML 源码，发布包大小以官方上传回执为准。
