# 内容笔记自动分析调整

## 修改计划

1. 先以原生WXML与复制链接回归复现额外授权步骤。
2. 删除正文中的访问分析首次选择卡片与重复状态按钮；更多菜单保留主动设置入口。
3. 仅公开内容笔记默认使用服务端配置的分析版本，不写入用户明确同意记录；主动关闭保持有效，其他路由策略不变。
4. 保留正文可读、配置失败关闭、退出/换号和旧分享归因边界。互动依然只要求登录，不增加分析授权。
5. 完成全量小程序回归、类型同步、凭据扫描与提交。效果图仅为设计预览，不代表体验版已更新。

## 当前实现边界

- 仅 `pages/contentreader/contentreader` 的图文、文章及视频笔记默认开启分析；服务端关闭或配置不可用时不采集。不会写入“用户明确同意”的本地记录。
- 更多中的设置可主动关闭；历史关闭选择继续有效，关闭不会被打开页面或告知版本更新覆盖。其他页面延续原有选择策略。
- 退出自动分析页时先尝试发送已合法产生的事件，临时暂停保留失败队列；主动关闭和服务端禁用仍清理队列。不会为了统计阻塞正文显示。
- 页面不再放“同意开启/保持关闭”卡片或重复状态行。互动接口本来只要求登录，与访问分析选择独立。
- 当前修改不增加后端接口；沿用已配置的分析版本。前一批评论/点赞/收藏与Word接口的上线仍依赖后端部署。
- 分享和首次加载/正常阅读效果图均为示例设计，不是体验版或线上截图；骨架样式仅用于效果图说明。
