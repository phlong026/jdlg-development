# 笔记阅读页按已确认效果图落地

本目录记录从旧笔记分支接回当前 `main` 的有效功能边界。正文完整性、公开/私密权限、联系授权、分享追踪和当前阅读页样式均以整合基线为准，不回退到旧分支页面。

## 页面与简化

- 去掉图文笔记图片上方的品牌字样；胶囊下方独立工具栏仅显示分享、更多。
- 图集滑动、完整显示、点击原图沿用原有展示内核，横图按比例铺开；竖图限制52%视口高度，以保留首屏标题。
- 独立标题、正文、标签、来源、真实评论与底部点赞/收藏/评论入口。视频保留既有播放器与菜单行为。
- 删除旧品牌样式和图文底部三大按钮。复制链接与访问分析移入更多，不再占用底部主操作区。
- 管理者菜单：编辑、幂等创建副本、复制文案、保存图片、固定版本 Word 导出、生成海报、笔记设置、删除。读者只有可用的阅读/复制/保存入口；管理菜单复用当前有效的服务端权限证明，写接口仍独立鉴权。
- 副本只复制当前阅读版本的内容及授权媒体，不复制发布状态、评论或分享记录。响应丢失后重试沿用同一幂等键；明确成功、换号或切换内容/版本后才使用新键。异步动作绑定账号、内容与加载代次；互动读写互斥，旧刷新不会覆盖成功写入。
- 没有承诺与微信原生笔记互通；私密项目笔记的受邀权限、版本、反馈及确认不变。本轮改版入口是内容工作台发布的图文/文章阅读页。

## 验证

- 新增菜单授权、副本幂等重试、换号/换版迟到响应、互动状态、评论 Unicode 上限、后端并发冲突和真实 WXML 编译回归。
- 原生微信开发者工具2.02.2609250打开独立、无网络的示例工程，使用生产WXML/WXSS、展示模型、菜单方法。首次检查发现原生按钮默认宽度覆盖工具栏、竖图过高；已修正并复查菜单位置、海报入口、正文标题、话题及评论区域。
- 原生示例使用本地庭院素材和明确标注的示例评论；不访问生产接口、不写入线上内容，不等同于真实账号及手机分享验收。尚需部署后以真实MySQL、账号及手机检查互动、相册授权、Word图片导出和分享接收端。原生示例0错误、8条告警；不声称零告警。
- 重现视觉示例：`node miniprogram/scripts/preview-note-layout.js` 输出临时工程目录，再以开发工具打开该目录。
- 最终检查结果以整合提交的交付记录为准。本轮无新增依赖、无数据库迁移，真机视觉、相册授权、真实 MySQL 并发和部署后手机分享仍是独立验收门。

## 发布与回退

本轮仅实现、验证和提交代码，未上传新体验版、未部署生产。新评论、点赞、收藏和公开笔记Word导出需要同时部署后端。前端遇旧后端404不影响正文，但新互动不可用。

后端接口见 [api.md](api.md)。无数据库迁移，按提交反向 `git revert` 可撤销。公开互动记录留在现有存储；回退代码不删除用户评论或其他业务资料。
