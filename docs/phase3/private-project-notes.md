# 私人项目笔记：业务规则与接口

日期：2026-10-27。本文依据当前 `service/tracking/project_notes*.go`、`service/route/project_notes.go` 和小程序 `pages/projectnotes`、`pages/projectnoteview` 的实际实现编写。

该能力目前只在开发分支实现，默认关闭，尚未发布甲第主服务或上传小程序体验版。它不代表内容创作、分享跟踪和消息通知三个模块已经完成生产验收。

## 1. 已确认的业务规则

### 固定分享版本

设计师先保存笔记草稿，再冻结版本，最后为该版本创建分享。分享记录只引用冻结时的 `version_id`；设计师后续修改草稿不会改变旧分享内容。更新后必须重新冻结并分享新版本。

版本保存完整标题、正文格式、正文、封面和媒体快照。确认记录也绑定精确的 `project_id + version_id`，一个版本最多有一条有效确认。新版本需要指定业主再次确认。

### 查看权限

私人分享同时检查以下条件：

- 访问者已登录甲第小程序，且账号仍有效；
- 账号是该项目当前有效的受邀成员；
- 分享 token 存在、未撤回、未过期，并且仍指向原冻结版本。

拿到或转发链接不会增加权限。移除成员后，该账号不能继续查看正文、媒体、反馈或确认；移除当前确认人时，服务端同时清空项目确认人。页面切换登录账号时会清除已加载的私人正文、媒体和表单，并重新校验权限。

### 反馈与确认

- 所有仍有效的受邀账号都可对当前固定版本提交反馈。
- 设计师在管理页处理反馈；一条反馈只能形成一个处理结果，重复提交相同结果返回原记录，改写已处理结果返回冲突。
- 只有项目当前指定且仍有效的受邀业主可确认版本。前端只采用服务端返回的 `can_confirm: true`，不根据本地昵称或账号缓存推断确认权。
- 处理反馈和确认版本是两个独立动作。设计师处理反馈不会代替业主确认，业主确认也不会自动标记反馈已处理。

### 私有媒体

项目媒体使用独立的 `note_media_pending`、`note_media_object`、`note_media` 元数据，不写入企业普通素材 `media`。普通素材列表不能枚举项目媒体，即使知道媒体 ID，也不能通过普通素材接口读取。

管理端媒体地址限定到当前项目；受邀端媒体地址限定到当前分享 token 和冻结版本。草稿、保存和冻结均拒绝引用企业普通素材、其他项目媒体或类型不匹配的媒体。上传只接受：

- PNG、JPEG、GIF、WebP，单文件不超过 10 MiB；
- 标准 MP4，单文件不超过 50 MiB；
- 图片和视频尺寸必须可识别，宽高均为 1–20000 像素。

对象存储写入失败或结果不明时保留待完成记录，不做可能误删已引用对象的清理。

### 浏览记录、提醒与隐私删除

页面下载必要媒体、设置正文并完成页面数据更新后，使用稳定 `event_id` 上报一次打开。打开事实、`notice_event` 和通知队列在同一事务写入，消费者随后生成消息中心记录。提醒对象是创建该分享的实际分享人；分享人自己打开不提醒。这是页面打开记录，不等于用户完整阅读了正文或看完视频。

通知只保存通用文案和 `project_id + version_id` 管理路由，不写入私人正文、分享 token 或媒体下载地址。生成站内消息或对外投递前，服务端再次检查访问者未删除数据、成员仍有效、分享未撤回或过期、版本仍匹配、实际分享人仍有项目管理授权。

隐私删除会清理该访问者的 `note_open` 和通知事件，并阻止同一账号重新写入浏览记录；它不会删除项目、冻结版本、反馈、处理结果或确认等业务记录，也不改变仍有效成员的正文查看权限。

## 2. 权限和通用请求约束

所有接口前缀为：

`/api/v1/miniprogram/project-notes`

所有接口均使用现有小程序登录认证、封禁账号检查和 `Cache-Control: private, no-store`。功能仅在 `PROJECT_NOTES_ENABLED=true` 时开放；示例配置保持 `false`。

管理接口还要求当前小程序账号具有 `can_manage`，owner 在当前授权范围内，并且项目的 `designer_id` 等于当前账号。仅 owner 相同但不是该项目设计师的账号不能管理项目或读取项目媒体。

JSON 请求体最大 128 KiB，拒绝未知字段和尾随内容。除媒体上传外，客户端不传 actor、designer 或 tenant，服务端从当前登录态和授权范围取得这些身份。

## 3. 管理接口

| 方法 | 路径 | 核心请求 | 结果与约束 |
| --- | --- | --- | --- |
| `GET` | `/projects` | 查询：`limit`、`cursor` | 当前设计师项目分页；默认 30，最大 100，返回 `items`、`next_cursor` |
| `POST` | `/projects` | `name`、`owner_id`、可选 `crm_id`、`customer_ref` | 创建项目；名称最多 100 UTF-8 字节。非空 `customer_ref` 必须是当前设计师可关联的本人客户；当前 `crm_id` 非空直接返回 403，见“未完成项” |
| `GET` | `/projects/:id` | 无 | 返回项目及成员、草稿、版本摘要、分享、反馈、处理和确认；每类最多最近 50 条，并返回各类 `truncated` 标识 |
| `PATCH` | `/projects/:id` | `expected_revision` 及可选项目字段、`customer_ref` | 乐观锁更新项目；未提供 `customer_ref` 保持原关联，空串解除，非空值经本人客户权限校验后绑定或更换；不接受 `crm_id` 代替客户引用 |
| `GET` | `/projects/:id/versions/:version` | 无 | 精确读取同项目的固定版本；仅当前项目设计师可读，不受详情最近50条窗口影响 |
| `GET`、`HEAD` | `/projects/:id/versions/:version/export.docx` | 无 | 按精确冻结版本生成Word；成功响应前再次验证当前设计师授权 |
| `POST` | `/projects/:id/members/:account` | 空对象 | 邀请现有且有效的小程序账号；`:account` 是数字用户 ID |
| `DELETE` | `/projects/:id/members/:account` | 无 | 撤销成员；若其为当前确认人，同时清空确认人 |
| `PUT` | `/projects/:id/confirmer` | `account_id` | 指定确认人；账号必须是当前有效成员 |
| `POST` | `/projects/:id/notes` | `title`、`body`、`body_format`、可选 `cover_media_id`、`media_ids` | 创建草稿；标题最多 80 字符、正文最多 100000 字符、媒体最多 50 个 |
| `PATCH` | `/notes/:id` | 同草稿字段，另含 `expected_revision` | 乐观锁保存新修订；修订号不一致返回 409 |
| `POST` | `/notes/:id/versions` | `expected_revision` | 从当前精确修订冻结不可变版本 |
| `POST` | `/versions/:id/shares` | `expires_at`、`idempotency_key` | 为固定版本创建分享；有效期必须在未来 |
| `POST` | `/shares/:id/revoke` | 空对象 | 撤回分享，原 token 立即失效 |
| `POST` | `/feedback/:id/resolve` | `reply`、`idempotency_key` | 设计师处理反馈；回复最多 4000 UTF-8 字节 |
| `GET` | `/projects/:id/media` | 查询：`limit`、`cursor` | 当前项目媒体分页；默认 30，最大 50 |
| `POST` | `/projects/:id/media` | `multipart/form-data`，且只能有一个 `file` 字段 | 上传并写入当前项目私有媒体；整个请求上限 51 MiB |
| `GET`、`HEAD` | `/projects/:id/media/:media` | 无 | 仅当前项目设计师读取或探测媒体；支持既有媒体代理的范围读取 |

`body_format` 沿用内容系统的 `plain`、安全清理后的 `rich_text` 和结构化 `article_v2`。当前小程序对 `rich_text`、`article_v2` 正文采用只读方式，修改标题时会原样带回正文、封面和媒体，避免将结构化内容降级为纯文本。

创建分享时，raw `share_token` 只在首次成功响应返回，数据库只存散列。相同幂等请求重放会返回同一分享并标记 `replayed`，但不会再次返回 raw token；前端会保留首次返回的本机凭证。若响应结果不明确或本机凭证丢失，页面明确要求从版本管理恢复，不会盲目重试冻结，也不会私自撤回现有分享。

## 4. 受邀账号接口

| 方法 | 路径 | 核心请求 | 结果与约束 |
| --- | --- | --- | --- |
| `GET` | `/shared/:token` | 无 | 返回固定 `project`、`share`、完整 `version`、当前版本的反馈、处理、确认，以及 `can_confirm`、`activity_truncated` |
| `POST` | `/shared/:token/open` | `event_id` | 幂等记录本账号打开；同 ID 用于其他账号或分享返回 409 |
| `POST` | `/shared/:token/feedback` | `text`、`idempotency_key` | 对固定版本提交反馈；正文最多 4000 UTF-8 字节。响应丢失后必须用相同键重试 |
| `POST` | `/shared/:token/confirm` | `idempotency_key` | 仅当前指定业主确认精确版本；项目和版本维度唯一 |
| `GET`、`HEAD` | `/shared/:token/media/:id` | 无 | 只能读取该分享固定版本实际引用的封面和媒体 |
| `POST` | `/shared/:token/media/:id/playback` | 空对象 | 已登录且头像、昵称完整的受邀账号，为 MP4 视频申请短时播放地址 |
| `GET`、`HEAD` | `/shared/:token/export.docx` | 无 | 登录受邀账号导出当前分享的固定版本；撤销、过期或成员被移除后拒绝 |

受邀端反馈、处理结果各最多返回最近 50 条；超过时 `activity_truncated=true`。分享响应不返回 raw token，媒体 URL 也只使用该分享的鉴权代理路径。

小程序原生转发继续携带同一 `pns` 分享 token。接收人仍须登录且已被邀请；转发本身不会创建成员或变更确认人。

视频播放响应沿用标准信封，`data` 为 `{url, expires_at}`；相对地址须补齐 API 域名。原生 `video` 使用返回地址直接分段读取，不先 `wx.downloadFile`。播放 GET/HEAD 为 `/api/v1/shared-video/:ticket?exp=...&sig=...`，无需登录头，但每次核验账号、资料、分享、成员及素材权限，支持 Range 206/416。票据有效期10分钟，失败后由用户点击重新加载获取新票据；不把长期登录凭据放入 URL。票据仅存在当前进程内，重启失效，多实例需共享票据存储。退出登录本身不会立即撤销已签发票据；账号停用、资料失效、分享撤销或成员移除会拒绝后续请求。

## 5. 幂等、并发和分页

- 草稿保存、版本冻结使用 `expected_revision`，防止旧页面覆盖新修订。
- 创建分享、提交反馈、处理反馈、确认版本都要求合法 `idempotency_key`。
- 分享创建的幂等语义绑定当前设计师、版本和有效期；同一个键用于不同请求返回 409。
- 反馈幂等语义绑定分享、账号、版本和正文。小程序在失败重试时保留相同键，成功、修改正文或切换账号后才清除。
- 确认记录按项目和版本唯一。即使后续更换指定确认人，已经确认的旧版本不会生成第二条确认；新冻结版本可由当前指定业主确认。
- 项目和媒体列表提供游标分页。管理详情不是可无限翻页的审计接口，每类只返回最近 50 条并标记截断。
- 消息中心跳转携带 `project_id`、`version_id`。页面通过精确版本接口进入只读固定版本视图，不受管理详情最近50条窗口影响，也不会用对应笔记的最新草稿替代旧版本；点击“返回当前草稿管理”才恢复草稿编辑。

- 主服务尚未发布该代码，`PROJECT_NOTES_ENABLED` 仍默认关闭，小程序也未上传体验版或生产版。
- 当前成员邀请输入现有甲第小程序数字账号 ID；按手机号、昵称搜索或选择业主的账号检索界面尚未实现。
- CRM 关联尚未接通。创建项目时 `crm_id` 必须为空，非空请求会明确拒绝，不能把客户端输入当作 CRM 授权证明。
- 管理详情活动记录每类最多50条并提示截断；正文已可通过精确版本接口独立读取，反馈和确认的完整历史分页仍需补齐。
- 私人固定版本Word下载已接入小程序管理端和受邀端。Word按文字、图片的语义顺序导出，视频在甲第方案中查看，不承诺微信CSS原排版或Word内播放视频；PDF尚未实现。下载成功只表示得到临时文件，页面仅在系统打开文档成功后提示已打开。
- 受邀端保存原图会重新请求当前分享的鉴权媒体接口，不复用已缓存文件绕过撤销。相册保存失败明确提示权限或重试，账号切换、页面离开、项目/版本变化后的旧下载不会继续打开。
- 真实甲第设计师账号、受邀业主账号和真实 COS 媒体的真机多角色验收尚未进行。
- 浏览提醒的站内持久化链路已实现；服务号“华匠邦建科”的 AppID、模板字段、关注和身份绑定、真实收件人仍待后期补充，因此没有服务号真实送达证据。
- 本能力不包含匿名查看。也不能从小程序转发结果推断微信送达、阅读回执或转发链中的每个中间人。
