# 项目资料、AI说明与业主协作交付记录

本增量对应 C07、N01、N02、N05、N06、N09、S02，以及 N11 的导出内容部分和 S04 的分享封面代码部分。

## 可操作流程

1. 在私人项目内维护名称、地点、建筑面积、层数、风格。保存使用项目修订号，冲突时重新读取，不静默覆盖。
2. 选择项目内任意笔记、新建另一条笔记，或选择已有固定版本。旧通知仍进入指定版本，不替换为当前草稿。
3. 从可编辑笔记进入 AI 文案。仅带入明确存在的项目事实和当前正文，不带客户编号、业主意见或私有素材路径。采纳结果追加回原笔记，用户核对后保存；账号、草稿、版本或忙碌状态变化时拒绝回填。
4. 草稿未保存的修改不能直接冻结。冻结后项目资料快照与正文一起保留，后续资料编辑不会改写历史 Word。
5. 业主可主动提交三档满意度和文字意见。反馈固定关联账号、项目、方案版本，并产生设计师站内提醒。
6. 设计师直接点击具体反馈填写回复，无需抄写反馈编号。失败重试沿用同一语义幂等键。
7. 当前方案状态与历史确认分离：旧方案的反馈、确认继续留存，不覆盖当前新方案状态。指定业主才能产生“已确认”，该状态不等于 CRM 成交。

## 分享和阅读回执

读取私人方案本身不再自动发送实名回执。页面明确说明发送内容，用户主动点击“告知设计师我已查看”后才提交 `acknowledged:true`；服务端拒绝缺少该标记的请求。拒绝或不发送不影响阅读、反馈、导出。只使用已通过成员权限下载的方案封面生成主动分享卡片，不暴露私有对象地址。

## Word

导出使用版本自身的项目快照，按已知字段输出可编辑文字。缺少快照的旧版本不从当前项目补写未知资料，继续保留原有导出行为。图片读取、导出前后权限复核、大小和超时限制沿用原实现。

## 验证与边界

本地测试覆盖项目修订冲突、历史状态隔离、满意度幂等、通知去重与恢复、私密权限、笔记/版本切换、AI账号切换和回填、未保存冻结保护、Word快照、WXML原生编译。未调用付费模型、未发送真实外部消息，未部署。

仍需真实角色与设备验证：AI生成及费用、微信接收卡片的封面、WPS/Word打开与原图保存、服务号实收。本次同时包含完整历史分页、老反馈与草稿精确读取、笔记复制和草稿软删除。前后台恢复会重验权限并保留未保存输入，切换对象前提示放弃未保存修改。收藏、正式CRM绑定及授权发布作品未包含在本提交中。
