# 图文与视频笔记原生验收及文字精简

基于已合并且已设为体验版的8.0.11源码 `1f22a18`，本轮只调整内容编辑页图文/视频模式的显示文字，不改AI接口、计费、登录权限或保存发布逻辑。

## 修改

- 图文/视频编辑时不再显示大块例行“有未保存修改”横幅；已有内容顶部的“未保存”仍保留。
- 删除空视频“添加视频”下重复的来源说明；来源选择仍通过原操作进入。
- 删除已经标明选填的分享文案框重复占位文字。
- 封面已有角标，选中操作文案由“已设封面”收短为“封面”。
- 按钮已有“生成中”时不重复显示生成进度；生成发生改写时显示恢复入口，避免再叠加“已生成”。如果结果与原文相同、没有恢复按钮，仍保留一条“已生成”，避免完成后毫无反馈。
- 错误、余额、权限、归属版权、恢复原文和真正操作结果均保留；文章模式保持本轮前的显示。

## 原生环境与证据边界

微信官方开发者工具和miniprogram-automator，真实小程序原生组件、输入与点击；使用专门的本地MySQL/Redis/Go接口与已有虚构账号。登录组件实际发起签名profile请求，并返回200/code0后才挂载业务页，没有手动设置authenticated或挂载标志。

验收副本使用独立storage前缀，首行安装适配器；真实AppID标准token/userInfo在注入前后保持一致。所有业务API指向loopback；外部API与业务写入被验收守卫阻断。SSE用受控分段结果测试尾帧、取消和迟到响应，因此这里验证原生交互，不证明真实供应商可用、计费或生成耗时。临时适配器、虚构凭据及本地URL不进入产品源码或上传包。

此前验收副本只改了profile-access的fallback，漏改实际执行校验的login-guard/nickname-guard；本轮在测试副本统一修正地址，实际profile200、context/media请求均已验证。页面隐藏时保护区清空是App.onHide上锁行为；不把工具后台状态的白屏判成产品登录故障。
