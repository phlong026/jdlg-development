# 内容工作台客户视角复核｜2026-11-02

## 依据与结论

独立查看微信原生截图 ux-contentworkbench.png、ux-contentwriting.png、ux-contentedit.png，并只读检查当前未提交差异。截图只证明所展示的页面和状态，不证明全部菜单及异常流程通过。AI截图早于新增麦克风图标，图标及其新位置仅完成代码核对。

本轮改善了“入口是什么、下一步点哪里、内容是否占主位”三个核心问题，方向合理。仍有状态反馈和内容辨识问题，应作为下一轮具体验收项，不宜以视觉变整洁代替流程验收。

## 已修正的设计原理

1. **导航与页内筛选分开。** 工作台“我的内容”成为栏目标题，“项目合集/资料库”带箭头，避免把navigateTo跨页导航伪装成当前页Tab；只有图文/视频/文档保留分类选项形态。
2. **信息层级围绕当前任务。** 链接导入/AI/分享工具由高卡片变轻量横排；余额移出搜索和内容之间；搜索、类型、列表连续。对比同尺寸旧图，第一条内容的封面约从620px上移至518px，获得约100px截图空间。此数值是截图近似坐标，不是设备CSS像素指标。
3. **每个状态有明确主动作。** AI初始状态只有“生成文案”；生成中提供停止；有结果后再出现重新生成与采纳。将深聊移出固定操作区，减少竞争与底部堆叠。编辑器保存/预览固定在底部，短文状态可直接操作。
4. **直接操作有清楚对象。** 合集候选补封面，勾选具有选中样式；已选条目先展示作品再显示操作，帮助确认“正在移动哪个作品”。预览增加封面、简介、作品目录，明显优于纯标题清单。该项来自差异审查，未包含本次三张截图。
5. **空态给出动作。** 资料库空态可直接浏览可用内容；可用内容出现搜索入口，生成记录不再只挂在某个列表尾部。无需靠长段教学解释。
6. **风格一致服务识别。** 暖白背景、棕金动作色、系统字体保持，减少页面跳转时的视觉割裂。没有为了“高级感”引入另一套品牌或装饰。

## 仍需处理或验证的问题

### P1：AI校验失败可能看不到原因

contentwriting.wxml 的 error/notice 在结果卡及优化区之后；ux-contentwriting.png 首屏该位置已经低于固定底栏。quickGenerate在资料为空时仅设置error，未滚动或聚焦字段。用户看到可点击的“生成文案”，点击后可能以为按钮失效。

建议：将当前失败原因放在固定操作区上方；缺资料时同时定位创作要求输入框。不要追加常驻教学文案。验收空资料、服务失败、余额不足、长结果失败四种情况，保证一眼能看到原因且能直接恢复。当前是截图布局与处理逻辑共同支持的风险判断，尚未逐一触发。

### P2：长文本下的操作密度仍高

编辑器空白状态清楚，但有正文后每块仍可出现转标题、转引用、上移、下移、移除等按钮。当前flex-wrap和80rpx高度修复了挤压，却也增加长文高度。合集每项五个操作仍常驻，长列表用户要反复扫过。

建议后续只对当前块显示编辑动作，或把格式/低频操作收进明确菜单；排序采用显式排序状态。先用20段正文、20个合集作品检验，不要依据空白页认定已经解决。

### P2：资料辨识仍不够

资料库的原始媒体选择仍是标题+选择按钮，重名“图片”缺少缩略图；已选内容仍无搜索。新增可用内容搜索是改善，但不能等同全资料库可查找。

建议下一步先补图片/视频缩略图与文件类型，给已选内容提供搜索或明确筛选范围。不可把私密资料包和公开内容当同一个素材列表。

### P2：不同AI入口的操作预期仍不完全一致

快速生成就地输出，精简/扩写/调整语气仍跳AI对话。虽然底部已不再误称所有生成都跳转，但同页“编辑优化”仍容易让用户期待直接改写当前结果。建议实测跳转、返回、采纳是否顺畅；若保持跳转，使用箭头或次级入口样式表达去另一页面，避免再增加长篇解释。

### P2：需用设备验证的触控与弱文字

工作台工具72rpx、跨页入口76rpx比原卡片紧凑；编辑器部分二级按钮也偏紧。应在窄屏和大字体下核验文字不截断、相邻入口不误触；可以扩大透明触控区域，不必增加视觉块面积。内容状态和日期仍为偏浅灰色，建议以真实屏幕可读性验证，优先保留“已撤回/草稿/已发布”等决策信息。

## 本轮建议验收顺序

1. AI空输入点击生成，确认错误立即可见；长结果状态确认操作条不遮最后内容。
2. 编辑器20段正文，测试保存失败、键盘展开、返回编辑、预览发布。
3. 合集长标题、多作品、无封面和真实封面，检查预览与客户阅读页的一致性。
4. 工作台跨页返回保持搜索/分类；不同权限与归属数量检查工具条和入口布局。
5. 资料库重名媒体选择、选用后返回、失效引用、搜索零结果。

## 随后完成的整改

- P1错误反馈已修复：完整错误进入底部按钮上方；同宽排版占位保证正文不被错误条遮挡。新增原生WXML渲染回归覆盖。
- 语音入口按用户反馈改为麦克风图标+“按住说话”，输入区右对齐；88rpx触控高度，按住显示“松开结束”并高亮。不用纯图标猜手势，不增加大虚线框。
- 工作台跨页入口补显式width:auto，避免微信原生按钮默认宽度造成间距过大。
- 已知三类AI产品导航名称与运营提示词分离，界面恢复正常中文；服务端提示词原始数据仍乱码，生成HTTP500仍未修复。

## 仍建议优先推进

1. 完成服务端可用性修复：项目/导入开关、AI上游与乱码数据；界面整洁无法替代能完成任务。
2. 长文和多作品按“当前对象”呈现操作，减少每一项都常驻全部按钮；先用20段/20作品与键盘状态验证。
3. 原始素材选择补真实缩略图，已选用内容补服务端搜索；不能先下载完整视频充当缩略图。
4. AI精简/扩写当前仍跳对话，下一步统一就地优化与采纳，或明确跳转指示；保留费用与来源约束。
5. “我的”页设计师入口应结合角色频率提高优先级，普通用户继续保留账户和订单路径；需要不同角色实际账号再验收。
