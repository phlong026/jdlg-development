# 客户视角布局优化计划

基线：原生五页截图与967项回归。现有字体、暖白棕金品牌、权限和业务边界保留。

1. 内容工作台：区分栏目、跨页入口、筛选；压缩工具占高，让内容靠前。
2. AI文案：底栏固定单排，生成/停止/采纳分状态；深聊移正文；固定产品导航名称，运营指令单独保留。
3. 合集：预览包含封面/简介/作品缩略图；编辑按钮与作品排序动作按主次布局。
4. 资料库：空态给直接下一步，可用内容开放既有搜索；移出空列表卡内的生成记录入口；统一背景与按钮颜色。
5. 编辑器：内容区域与工具明确主次；主操作与正文间距/对齐以原生截图复核。

按页面分工，先行为回归后布局；无新依赖、无全局字体替换、无凭空填充内容。每轮记录原生截图与视觉评估，不将样式通过等同服务端验收。
