# C04 内容草稿软删除

## 可删除范围

只允许删除当前账号已授权 owner 下的、从未发布的草稿：

```text
status = "draft"
version = 0
expected_revision = 当前 revision
```

已发布、已撤回、存在历史发布版本或已被分享/原生引用的内容均拒绝删除。已发布内容即使后来又保存为新草稿，仍然保留 `version > 0`，因此受保护。

## 软删除行为

- `DELETE /api/v1/miniprogram/workbench/contents/:id`
- 请求：`{"expected_revision": 3}`
- 响应：`{"content_id":"...","revision":4,"status":"deleted","deleted_at":"..."}`

服务端保留原 `content` 记录，将状态改为 `deleted` 并递增 revision。内容工作台列表和详情查询不再返回该草稿；保存、预览、发布、撤回和导入幂等重放都不能将其恢复。

前端“删除草稿”与“撤回已发布内容”为两个独立动作。删除确认框明确说明：它不撤回任何已发布内容，也不删除原媒体。

## 媒体删除边界

本增量不提供媒体物理删除。现有媒体可被草稿、历史版本、导入结果、项目资料等多种记录引用；在没有一个能完整、可靠证明“全局无引用”的服务端检查前，物理删除保持禁用。

## 未包含

- 草稿回收站或用户自助恢复。
- 媒体引用计数、延迟清理任务或 COS 物理删除。
- 已发布版本的删除；该类内容继续使用撤回流程。
