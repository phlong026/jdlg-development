## 验证规则

- 使用官方开发者工具、真实本地 API 和隔离的虚构账号；不把接口 mock 当作集成证据。
- 逐张比较参考与当前原生截图，核对信息顺序、字号、间距、媒体区、按钮和弹层；仅无溢出不能判定复刻通过。
- 保留原生状态栏、胶囊和底部安全区。真实名称、数量、图片、视频比例及无封面空态允许随数据变化，不伪造样例数据或图片。
- 私密笔记保留账号、项目、版本和媒体权限；页面精简不能删除客户协作能力。
- 截图或测试失败时记录失败原因，修复后重新采集；未实际核验的项目保持待验。

## 简化后的业务路径

- 图文：新建内容 → 图文笔记 → 选图、填写标题及选填介绍 → 保存草稿或发布；预览保持可选。
- 视频：新建内容 → 视频笔记 → 选择来源和视频、填写标题及选填介绍 → 保存草稿或发布；私聊和朋友圈文案不必填写。
- 项目笔记：新建项目只填项目名称及有多个可用归属时的必要归属 → 直接写笔记；已有项目直接新建笔记。关联客户、项目资料、AI辅助、预览、固定版本管理和导出不构成常规创建前置步骤。
- 发给客户：必要时保存当前稿 → 复用匹配的固定版本或创建固定版本 → 发送预览 → 微信联系人选择。编辑后不会改变已发送固定版本；不会自动向客户发送消息。

## 已保留的能力与数据缺口

- 文章、文件、项目笔记、内容版权、归属和短注释保留在二级入口；没有因为减少文字而删除保存字段。
- 客户回执、反馈、版本确认、下载、协作历史以及固定版本权限继续保留。缩略图和 EventChannel 回调核对当前账号及具体内容，迟到响应不能回填其他账号或项目。
- 项目列表接口没有项目封面及最新笔记摘要，当前使用统一图标占位，未伪造照片，也未通过逐项目请求制造 N+1。详情笔记已有媒体信息，可显示真实图片。列表照片仍需要后续兼容性数据契约，不能把图标占位称为和样例照片完全一致。
- 当前公开内容预览契约没有已确认的作者头像和作者资料，未伪造样例作者；真实媒体按其宽高比展示，竖图会比样例横图占用更多高度。
- 因上述数据差异、原生安全区以及待验项，本报告不声称 18 张逐像素一致。
