## 不能混同的边界

- 原生CGO全量/route测试受本机已有 `go-m1cpu` 在Go1.26/macOS初始化SIGSEGV影响；使用CGO_ENABLED=0全量验证，相关纯Go包另行开启race。没有把此本机初始化失败称为测试用例失败。
- govulncheck、gosec、staticcheck当前未安装；没有新增依赖来绕过限制。go vet和改动文件凭据扫描已执行，不能等同完整依赖漏洞审计。
- SQL测试为脚本驱动，CDP为受控假连接，未在真实MySQL执行迁移/并发锁竞争，未启动真实Chromium。
- 唯一当前外部样例检查为公众号匿名GET：报告样例返回18165字节风险控制页，解析器阻断为risk_control。未调用付费网关、元宝账号、真实媒体CDN，不据此宣称视频成功。
- 原HTML安全归档/复杂样式保真、小红书纯图文、私有COS适配尚未实现；原排版正式范围未以此增量结案。
- 未部署服务、修改Nginx/进程环境、执行迁移、上传小程序、提交审核或发送服务号消息；未做真机与多角色验收。
