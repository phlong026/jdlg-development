## 上线和回退边界

此代码版本部署前先备份并执行 `service/sql/customer_lead_identity_routing_up.sql`，增加可兼容身份列及索引并回填；不改变负责人、业务状态和 updated_at。新后端启用前迁移必须成功。此次只合并源码，未在生产执行 SQL。

源码可 revert 最终汇总 PR 的 merge commit（保留第一父提交）。整合前主线标签为 `checkpoint/unify-main-20261113-aa81e53`；来源分支完整保留在 `archive/20261113/<原分支名>`。回退数据库前先切回不依赖新列的旧后端，并备份身份快照列，再审慎使用 down 脚本；删除列会丢失线索身份快照，不能只靠 Git revert 恢复。笔记创建幂等 tombstone 留在现有 records 中，不需为代码回退删除。
