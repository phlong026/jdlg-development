# 销售模块重做 · 设计说明（2026-10-20）

范围：只做前端页面；不改后端接口、数据库、客户阶段/意向/咨询分类枚举；「新增客户报备」表单字段、校验、保存逻辑一字不动（只换外层容器样式）。

## 0. 统一规范（沿用总控台字号体系）

| 项 | 值 |
|---|---|
| 页面标题 / 分区标题 / 正文 / 辅助 | 20px/700 · 16px/700 · 14px · 12px（最小） |
| 按钮高 / 圆角 | 40px（手机 44px）· 12px；卡片圆角 16px |
| 主色 | rgb(139,94,60)；浅底 #f6eee3；卡片白底 + 1px 暖灰边 |
| 数字 | 简报大数字 28px/700（手机 24px），tabular-nums |

新增样式全部放在新文件（`salesModule.scss`、`customerSettings.scss`），用 `sx-` 前缀；不改 `customerLeads.tsx`、`shareTracking*`。

## 5. 客户系统设置 /customer-settings

只有 `scope === 'platform_admin'` 才渲染；其余（含 crm 主管/顾问）直接重定向到 `/`，导航也不出现（fail-closed）。

手机：顶部三个分段（企微同步与接入 / 账号与权限 / 归属绑定检查），下方单列内容。
电脑：左侧 220px 三项竖向菜单，右侧内容；内容组件为原 SyncPanel + PushStatus、AccessPanel、归属绑定完整性，逻辑与文案原样搬迁。

## 6. 权限矩阵

| 账号 | 导航 | 可进页面 |
|---|---|---|
| platform_admin | 销售（总览/线索/客户）· 系统设置 ·（含客户系统设置） | 全部 |
| crm 主管（crm_only + admin） | 客户管理（保持现状） | /customer-management、/share-tracking |
| crm 顾问（crm_only + staff） | 客户管理（保持现状） | 同上，仅本人客户 |

crm_only 的路由白名单与导航不扩大，因此 /sales-overview 与 /customer-settings 对其重定向；前端守卫用 `scope === 'platform_admin'` 的肯定判断。
