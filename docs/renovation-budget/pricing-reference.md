# 装修报价参考计价 v1

## 定位与边界

本版是对用户提供的土巴兔报价分项和 100 ㎡示例数据的参考实现，版本号为 `renovation-reference-v1`。它用于装修预算测算，不改变原有建房预算的数据、公式或权限逻辑。

已知边界：

- 面宽、进深、层数和层高只记录为房屋信息，v1 不从它们推导新的工程量。
- 不使用城市或省份价格系数。
- 经济/标准/品质的倍率为 `0.7 / 1 / 1.2`；旧房再乘 `1.1087`。原资料没有给出完整的“经济档删项”和“品质档加项”名单，因此 v1 只对已选参考清单应用倍率，不编造项目。
- 参考分项只提供“主材”和“人工/辅材合价”，无法在每一条明细上真实拆分人工与辅材。总览中将非主材工程费按参考总体比例 `12058:28952` 分配为辅材和人工；这是参考分布，不是分项成本明细。
- 房间数为 0 时，该空间整体不计费。只有资料明确按室/厨/卫/阳台数量计算的项目才随数量增减，其他项目按原资料给定的固定工程量或面积公式计算。

## 计价口径

1. 分项基准价：`工程量 × (主材单价 + 人工/辅材合价)`，按元四舍五入。
2. 工程总额：基准主材单价和人工/辅材合价分别乘装修档次倍率和新/旧房倍率，作为当次展示的有效单价；每个分项用“工程量 × 有效单价”按元舍入，再汇总分组、空间和工程总额。
3. 管理费 `10%`、设计费 `4%`、税金 `3.4%`均以当次重算后的工程总额为基数。默认勾选管理费和设计费，不勾选税金。
4. 取消分项后仍保留原工程量和单价，仅将 `included=false` 且金额置 0，便于恢复。

## 入参与安全限制

- 面积 `1..100000`；层数为 `1..20` 整数；各空间数为 `0..50` 整数。
- 面宽和进深可不填（`null`/空字符串/`undefined` 统一记为 `null`）；层高未填时默认为 `3.0m`。已填尺寸必须为有限正数，面积、尺寸、工程量均拒绝 `NaN` 和无穷值。
- 可调整工程量限制为 `0..1000000`，未知项目 ID 会直接拒绝。
- 输入、楼层信息和每次结果均做独立拷贝，后续修改调用方数据不会回写历史报价。
