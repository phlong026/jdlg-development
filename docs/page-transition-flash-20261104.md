# 页面跳转闪屏修复

按以下顺序交付，每步先复现状态问题，再执行回归验证：

1. 统一核验等待框架和页面底色，导航首帧使用真实设备尺寸；不提前挂载受保护内容，不修改授权规则。
2. 同账号返回时保留已加载的列表、正文和工作台，后台确认新数据；换账号、注销、真实失权仍清理。
3. 导入能力区分等待与不可用，避免短暂错误提示；直接导入避免等待无关内容列表。
4. 预热实际导航图片，刷新保留未变化的封面，避免先退回占位图。
5. 分类加载保持页面框架，图片尺寸更新保持卡片位置，编辑器文本不等待全部预览图片。

保持现有品牌资产和业务语义，不新增依赖。每步小范围提交，可用 git revert 独立回退。

验证包括状态行为测试、TS/JS 产物一致性、原生 WXML 编译、类型/语法检查和依赖扫描。模拟状态和本机编译不能代替开发版上传、真实账号真机操作与录屏验收。
