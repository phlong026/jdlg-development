# 分享图片与视频封面直接展示 · 2026-11-13

## 行为

- 共用 `utils/shareImage.ts` 默认仅绘制一层作品或视频封面，等比居中铺满固定画幅，移除渐变、半透明背景图、白色底板、阴影、描边和内层圆角。
- 好友卡片仍为 1000 × 800，朋友圈仍为 1000 × 1000；保持原始宽高比，允许裁边，不拉伸，也不额外填充黑边。
- 邀请海报显式使用 `contain` 和纯白补底，保留完整文字及二维码；绘制模式参与缓存键，避免与铺满封面混用。
- JPEG 导出前预填白色画布，避免透明图片的透明像素变黑；这层位于铺满图片下方，不形成边框或留白。
- 失败回退、失败后重试与并发合并沿用原实现；新的缓存文件名与旧装饰图分离。
- 本次仅调整共用分享图工具和邀请页对该工具的调用。内容阅读页原本直接返回 `content.cover.url`，本次不更换该链路。微信卡片展示图片封面，原视频播放 URL、播放器与视频文件均未修改，也未新增视频首帧提取。
