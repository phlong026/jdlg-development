# 工作台内容列表排序

`GET /api/v1/miniprogram/workbench/contents`

| sort | 排列规则 |
| --- | --- |
| 省略或 `created_at` | 按创建时间从新到旧。早期作品缺少创建时间时用存量记录的兼容时间。 |
| `page_views` | 按现有浏览统计留存期内的有效浏览次数从高到低，跨内容版本累计。同一访客多次有效浏览分别计数，同次数按创建时间从新到旧。 |
| `collection` | 按本人可管理的合集分组，分组按合集名称排列。同一作品属于多个合集时归入最近创建的合集。组内按创建时间从新到旧，未归入合集的内容最后显示。 |

按查看数排序时，`items[].page_views` 是匹配内容及授权归属的汇总值。该接口继续使用工作台管理权限。访客、分享及访问明细仍由各自接口校验查看权限。按合集分组时，有所属合集的作品返回 `items[].collection_id` 和 `items[].collection_title`。

关键字、内容类型和归属筛选先于排序和分页。下一页沿用原筛选、`sort`、`as_of` 和 `metric_version`，使用 `next_cursor`。修改排序或筛选时重新取第一页。合集成员或名称改变导致游标失效时返回 409，可刷新列表。
