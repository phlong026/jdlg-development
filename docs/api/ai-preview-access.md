# AI 预览与账号操作的访问边界

2026-11-11，本规则补充首页匿名浏览整改。公开浏览、账号鉴权和个人资料完整性分开处理；仅调整 AI 范围，原造价报告、设计师方案、资料包和项目笔记分享继续使用完整资料门禁。

## 匿名读取

以 `/api/v1/miniprogram` 为前缀，以下 GET 返回公开配置：

| 路径 | 数据 |
| --- | --- |
| `/ai/pricing` | 公开服务价格与可选生成规格 |
| `/ai-tools` | 已发布工具列表 |
| `/ai-tools/:id` | 正整数 ID 的已发布工具定义 |
| `/ai-tools/code/:code` | 单路径段 code 的已发布工具定义 |

价格场景采用固定白名单，每次最多请求8个不同场景；公共配置仅输出视频时长上下限，不返回任意后台 extra_config。工具预览不返回内部提示词后缀或模型专用引用图，已发布的用户预览图可同时作为生成参考图，仍属于公开展示资源。真实生成按所选工具与风格 ID 从服务端读取完整规则。

不得通过前缀匹配放开 AI 分享、个人任务、余额、上传或执行接口。其他 HTTP 方法及额外子路径不属于公开配置。

## 账号操作

AI 生成、提示词优化、服务端参考图上传、视频生成、任务查询，以及个人 AI 余额、历史与下载仍要求有效账号凭据。头像、昵称不是这些操作的前置条件。原有任务所有者校验、禁用账号限制、灵石扣费和下载权益验证保持生效。

未登录访问账号接口返回 401；不以匿名预览代替账号执行授权。受保护分享接口继续验证完整头像与昵称，资料不完整返回 428。

## 页面与跟踪

新增可匿名浏览的页面为 `aigenerate`、`aivideo`、`aitools`、`aitooldetail`、`aitoolworkbench`、`aicost`、`newminnantool`、`allrounddesign`，均位于 `pages/<name>/<name>`。仅允许浏览公开配置和编辑本地表单。个人 taskId、服务器上传和任务恢复仍需账号；匿名预览不得加载其他账号的缓存任务。

`generateprogress`、`generatehistory`、`generatedetails` 和个人测算结果 `aicostresult` 为账号页面，不允许匿名。个人测算结果按账号隔离本地存储；无账号归属的旧缓存不读取。对外造价报告及其他分享正文不属于公开表单，仍要求完整头像和昵称。

上述私人结果和历史页保留原 `collect:false` 排除策略，不建立跟踪 entry 或发送访问事件；账号可以使用不等于对外开放或纳入分析。

AI 表单页访问记录采用既有匿名凭据和账号关联机制；事件不携带提示词正文、参考图私人 URL 或输入参数。账号凭据不能作为匿名凭据使用。登录前后保留同一客户端的访问关联，切换账号不能沿用前一账号的任务与上传资料。
