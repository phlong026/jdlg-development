# 公开阅读与联系授权接口

本文对应 2026-11-12 本地实现，部署以发布记录为准。

- `GET /api/v1/miniprogram/templates/:id` 只返回已发布的广场模板；收费模板的未解锁响应不提供原图，安全衍生预览缺失时为空。账号详情、下载和写入仍执行各自鉴权及权益校验。
- 已发布内容及合集的固定版本可匿名读取；媒体读取继续验证内容引用、版本、撤回和归属。合集媒体支持 GET、HEAD、Range，私密工作台与定向项目笔记不因此开放。
- `POST /api/v1/miniprogram/public-share-links` 仅为已发布的公开内容或合集固定版本生成普通微信 URL Link，限制访问频率。该链接不携带跟踪分享凭证，带普通分享标记以避免接收页面建立访问分析会话。撤回后读取及新链接生成均受原权限校验。
- `GET /api/v1/miniprogram/customer-service/contact-consent` 查询业务联系同意状态；`PUT` 须携带当前用途和版本以及用户选择。该选择独立于登录、手机号验证和访问分析。
- 账号绑定手机号须当前用途及版本的有效同意才可用于业务联系；用户撤回后本地线索读取隐藏该来源号码。账号绑定手机号暂不外送 CRM；历史远端副本清理需另行执行。
