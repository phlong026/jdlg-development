# 页面分享与客户访问系统：交付与验收入口

## 当前结论

本分支提供首版功能实现、自动化回归和离线安全评审；尚未完成真实环境与设备验收，不能据此批准上线。业务采集、微信码和保留清理保持安全默认关闭。未经核验的 URL Link、公众号自动同步未开放。

- B1/B2：原有路由及权限清单、统一合同、服务端身份与归属、分享令牌、幂等事件、限流、持久化与可撤回入口。
- B3：原 57 个页面统一接入策略，新增通用 reader 后共 58 路由；21 个公开采集源、37 个隐私排除源。包含内容就绪、同意、前台时长、跨页、离线和换号边界。
- B4：同一菜单下客户与素材视角、日期筛选、稳定快照分页、会话轨迹、实际标题封面和原比例媒体。
- B5：自有/已授权素材手工录入、受控富文本、图片视频上传、草稿预览、不可变发布、撤回、统一阅读与原生分享。
- B6：当前匿名会话的可信登录关联、权限内 CRM 映射、可解释跟进参考与人工修正、同意撤回、删除墓碑、保留维护及审计。
- B7：后端、SDK、后台状态回归及独立代码评审已执行；真实数据库、CRM、微信、视觉与性能门槛未签收。

完整任务及依赖见 [开发计划](development-plan.md)，逐项前提、步骤、计量和证据见 [17 项验收清单](acceptance-checklist.md)。代码覆盖和业务验收是两个独立结论。

## 无微信码时的可操作入口

新建素材发布后，已获显式素材管理授权的小程序账号可在原“我的”页面展开“可分享素材”，查看标题、封面及已发布状态，打开固定版本 reader 并使用原生分享。服务端列表、打开及作者自访判断均重新校验 mini 账号和归属，不展示草稿或越权素材。没有新增独立分享页。

mini 与管理后台是不同账号类型；上线须给实际 mini 账号配置 tracking_access 的 enabled/can_manage/owner 范围，不能假定后台账号会自动映射。代码提供列表/打开入口，实际账号授权与微信设备验证仍待完成；没有二维码/URL Link 不再要求用户凭技术路径才能找到正文。

## 已知代码约束与后续优化

- 计时/队列阈值集中在 SDK 常量，调整须版本更新与回归；没有运行时配置界面。
- 跟进规则提供按归属隔离的不可变版本、1–90 天评估窗口及首版确定性阈值；版本并发校验、原因和审计、幂等重算均有接口和同菜单控件。默认近 30 天，不支持任意表达式或 AI 黑箱。已接入收藏成功及明确主动咨询提交；预约、报价和企微聊天因成功源/身份桥不足不冒充接通。详见 [规则合同](intent-rules.md) 与 [业务源核查](business-sources.md)。
- SQL 按租户、归属、时间和目标缩小候选，再读取必要完整会话保持计量口径；每事务累计限制 20,000 条/32 MiB，超限明确 422，不返回半份统计。宽窗口报表、巨大单会话及维护任务仍可能受限。
- PRD 的 10 万 PV/日、100 万存量事实、P95 小于 2 秒是建议服务质量目标；未取得达标证据。日汇总和查询预算不能替代 SQL 分组聚合、索引计划和真实压测。
- 原始数据过期后冻结日汇总仍含个人数据，受相同权限与删除约束；不能重建历史快照时明确 409，原始轨迹过期明确 410。
- 朋友圈首次同步回调无法等候服务端令牌，保留原分享；该次无令牌时不宣称可追踪归因，更不宣称送达。
- 原素材卡保存展示快照，不能冒充原业务正文历史回放；公众号原文外跳只能记录点击，不能观测外部阅读时长。
