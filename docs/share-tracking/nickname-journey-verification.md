## 修复范围

- 资料持久化：完整 profile 对历史可空字符串采用 NULL 安全读取；仅不存在时创建，读取异常不伪装成空资料；服务端 trim 和 Unicode 长度校验；原子 upsert 支持首次及同值保存。未迁移或清洗历史生产资料。
- 可选昵称完善：token 登录恢复资料检查；关闭欢迎弹窗后继续检查；账号隔离的“稍后完善”；原生 `input type="nickname"` 表单最终值优先，保存后实际 GET 回读一致才完成。浏览不强制填写昵称。
- 后台展示：真实 profile 昵称优先；有可信账号但缺昵称显示“用户 #ID · 未设置昵称”；匿名仍匿名。访客接口不额外暴露手机号或登录用户名。
- 分析选择：只有当前告知版本的明确同意才开始分析；未选择、拒绝及旧版隐式同意均不自动采集。设置页提供用途告知和选择，关闭后失效采集上下文及分享预热缓存。普通分享仍可用。
- 清缓存：仅移除已知临时缓存；保留登录 token、合法请求签名依赖、分析/隐私选择和用户草稿。设备签名值没有被用于新增身份推断。
- 普通公共页面：后台同时展示合法公共页面访问和素材访问，按 route 区分；私有页与权限边界不变。
- 朋友圈：统一包装器在内容就绪时预热同步 payload，统一缓存键、并发去重、账号/选择/内容/页面边界失效。首页、模板详情、测算入口、公开报告落地页使用纯 payload getter；实际手势才记分享意向。预热失败或尚未完成时普通分享回退，不能保证用户在网络响应前手势就有 st。
- 主动公开快照：私有测算结果不再自动创建公共快照；用户明确发布后才形成不可变公开报告，专用落地页使用服务端验证的快照 ID/版本。分析只存公开身份及通用标题，不把输入、答案或报告正文写入分析。失效/撤销快照拒绝采集。
- 渠道归因：分享创建时校验并保存目标渠道，兼容历史有效意向；令牌无效、过期、撤销、内容不匹配和无来源凭据分别保留可诊断状态，不冒充准确直接访问。预热本身不算已发起分享，分享意向也不证明送达。

## 全链路测试与允许的关联

`service/tracking/full_journey_test.go` 将真实 tracking 服务的 entry、分享、事件摄入和后台投影串在一起。覆盖首页 → 模板 → 已验证登录 → 测算入口 → 冷启动再访 → 公开快照 → 二次、三次分享，验证匿名到已验证账号的同会话关联、昵称更新回读、直接分享人、朋友圈筛选、重复 PV/时长去重、权限隔离和私有问卷排除。身份提供方与公开内容解析使用明确测试 fixture。

站内连续浏览只在有效 previous-entry、同客户端、合适身份及有效会话时间内延续来源。冷启动没有可信来源凭据时保留“来源未确定”；同一已验证 user_id 的再次访问仍归其账号，不根据 IP、昵称或设备相似性合并不同账号。真实账号切换终止旧上下文，拒绝把旧分享人缓存移到新账号。

昵称 HTTP/MySQL 测试使用真正鉴权中间件、SM4 请求签名及隔离 MySQL，覆盖 NULL nickname/phone、trim 保存、同值重复保存、读取回填、身份/头像逐字段更新不覆盖昵称、缺失资料恢复和数据库读取错误返回500，并核对 profile、账号列表和 tracking 同一 user_id 的昵称一致。

## 账号体系审计（未修改认证规则）

当前实现并非自动把同一个自然人的所有登录方式合并：

1. 微信按 openid、unionid 和历史迁移路径找内部账号；短信按 phone identity 找账号；用户名密码校验已有 users 行。
2. 微信手机号授权只写企业微信验证资料，不创建 phone identity。隔离 HTTP 测试确认仅授权后短信登录可创建另一 user_id；昵称留在 A、访问发生在 B 是可复现条件，尚未证明截图中的线上记录命中。
3. 明确登录并短信验证后调用 `/phone/bind` 才统一短信登录 user_id；手机号已有归属时返回40901，未自动合并。当前账号设置密码后，用户名密码登录回到同一 ID。
4. 同 openid/unionid 跨设备仍回到同账号；现代账号同设备不自动合并。历史32位散列 openid 的旧设备迁移分支仍可能复用旧 ID，需要单独安全整改决策，不能作为本轮推断同人的依据。
5. 审计还复现第二个独立手机号注册时空 openid 撞唯一约束。应另做兼容数据/索引核查及最小 NULL 写入修复；本轮未改变注册或绑定规则。

安全的后续统一身份方案应以已登录账号和可验证手机号/微信授权为证据，绑定到该内部 user_id；发生已有账号冲突时进入明确冲突处理流程。不能按设备、昵称或手机号授权页面的显示信息自动搬移昵称或合并生产账号。

3. 两个真实微信账号明确选择分析后，分别从首页/模板/主动公开报告首次及后续朋友圈打开、连续浏览、退出重进、再访和再次转发，核对同步 query 中 st、后台直接分享人、账号昵称、可见时长、重复上报与筛选。拒绝/未选择分析、快照撤销、私有页面应无采集，普通分享仍正常。
4. 上传、发布或部署均不在本次授权内，需另行确认。
