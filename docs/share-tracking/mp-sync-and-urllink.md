# 公众号文章同步与小程序 URL Link

状态：**已按微信官方接口文档实现，只用本地模拟服务测试，没有用真实小程序或公众号验证。** 两项都默认关闭。上线前必须按本文“验证步骤”在测试账号上跑通，不能把单元测试当作真实验收。

## 一、URL Link

用途：把已发布素材生成一个可在短信、邮件、H5 中打开小程序阅读页的链接。

- 调用官方 `wxa/generate_urllink`，路径是通用阅读页，query 带 `content_id`、`content_version` 和一个当日新建的分享令牌 `st`（小程序已有逻辑把 `st` 当作分享令牌，访问因此归因到该账号的分享）。
- 权限与微信码一致：开启开关、对素材归属有管理权限、该版本已发布且可读。服务端不接收调用方给出的路径或参数。
- 有效期 29 天，早于分享令牌的 30 天到期。链接按账号、素材、版本、环境和 UTC 日缓存在 `TRACKING_MEDIA_DIR`，原子写入，同一天重复请求不重复生成。
- 发布后在 `share_methods.url_link` 返回，后台编辑页已有“复制已核验 URL Link”按钮；生成失败只在 `message` 中说明，不影响发布。
- 接口是 `POST /contents/:id/url-link?version=N`，不是 GET：生成会创建分享并消耗微信额度，必须带管理端写操作的来源校验（`X-Tracking-Request: 1` 与同源 `Origin`），且每个账号每分钟最多 20 次（超出 429）。
- **access_token 不会每次重新申请。** 微信每个应用同一时刻只认一个有效 token，重复申请会让旧 token 在宽限期后失效。小程序的 token 与支付、用户资料、小程序码等功能共用 `function.GetAccessToken` 的进程内缓存，追踪不单独申请；公众号的 token 由追踪客户端自己缓存，到期前 5 分钟刷新，凭据轮换会换新 token，失败不缓存。

配置：

| 变量 | 说明 |
| --- | --- |
| `TRACKING_WECHAT_URLLINK_ENABLED=true` | 开关，默认关闭 |
| `TRACKING_MEDIA_DIR` | 与上传媒体同一个受保护绝对路径 |
| `TRACKING_WECHAT_ENV` | `release`（默认）/`trial`/`develop` |
| 小程序凭据 | 沿用现有 `WECHAT_APPID` / `WECHAT_APPSECRET` |

已知前提（来自官方文档，未经验证）：release 版本要求小程序已发布；接口有每日生成上限；个别主体类型可能没有该接口权限。失败时返回微信错误码，便于对照官方文档排查。

## 二、公众号文章同步

用途：把公众号**已发布**的文章复制成本系统的素材**草稿**，省去手工录入。

### 安全边界（代码保证，测试覆盖）

- **只生成草稿。** 不发布，不撤回，不自动改变任何已公开版本。每篇都要人工核对后走原有预览、发布流程。
- **不覆盖人工修改。** 同步记录它写入内容的签名；当前内容签名不同（有人改过）则不更新，计为“需人工处理”并列出。仅仅被发布过不算修改。
- **不恢复已撤回内容。** 本地已撤回的素材，公众号再更新也不会恢复。
- **公众号删除文章不会撤回本地素材。** 撤回会停止所有已有分享，须由人决定。
- **幂等。** 同一篇文章只对应一个草稿（按公众号 AppID + 文章 ID）；重复同步无变化即跳过；公众号有更新则更新原草稿（已发布的素材变成新草稿，原公开版本不变）。
- **图片会补齐。** 文章的“是否变化”只看正文和图片地址，不看图片是否真的到位，所以映射里额外记录图片导入状态（`off` / `partial` / `complete`）。开启图片导入后，凡是上次没有全部到位的文章（下载失败、该次运行额度用完，或之前是文本-only 同步、之后才开启导入），即使公众号原文没变，后续运行也会继续补齐，已下载的图片直接复用；全部到位后恢复“无变化”。只补未被人工修改、未撤回的草稿，其余保持原样且不产生下载。某张图片一直加载不出来时，每次运行仍会重试它并在计数里报告失败，但补不上新图片就**不改写草稿、不推进修订号**，不会打断正在核对这篇草稿的人。关闭导入不会让已完成的草稿重复更新。
- **权限。** 同步以配置的后台账号 `TRACKING_MP_ACTOR` 身份执行，权限取自该账号当前的 `tracking_access`（须启用且对配置归属有 manage），与登录会话同一套查询；手动触发者也须对该归属有管理权限。
- **正文清洗。** 文章 HTML 先转为受控结构（叶子 `section` 变段落、标题只保留两级、去掉样式/脚本/内嵌/微信小组件），再经过与手工保存相同的清洗。图片不在正文里内联。
- **来源链接**仅保留 `https://mp.weixin.qq.com/` 下的原文地址，用于核对。
- **图片默认不导入**（`TRACKING_MP_IMPORT_IMAGES`）。开启后：只从微信图片域名（`*.qpic.cn`、`*.qlogo.cn`）下载；连接建立时校验实际 IP，拒绝回环、内网、链路本地、运营商 NAT、文档与保留地址（含 IPv4 映射的 IPv6 形式，防 DNS 重绑定）；不跟随重定向；不走代理环境变量；每张 ≤10MiB，类型和尺寸校验同上传；每篇 ≤20 张、每次运行 ≤200 张；同一图片地址只下载一次。**这是服务端按外部给出的地址发起请求的唯一入口**，以前的设计原则是“不发起任意 URL 抓取”，这里是限定在微信图片域名内的有界例外，需要负责人确认后再开启。
- 凭据只来自环境变量，不进日志、错误和状态；状态里只有计数、固定原因和微信错误码。
- 状态与审计：每次运行记录最近结果（`GET /mp-sync`）并写审计 `mp_sync_run`（只含计数）。

### 配置

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `TRACKING_MP_SYNC_ENABLED=true` | 是 | 总开关，默认关闭。配置不完整时保持关闭并在日志和 `GET /mp-sync` 中列出问题 |
| `TRACKING_MP_APPID` / `TRACKING_MP_SECRET` | 是 | **公众号自己的**凭据，不能用小程序的 |
| `TRACKING_MP_OWNER` | 是 | 同步草稿的跟进归属 ID |
| `TRACKING_MP_ACTOR` | 是 | 执行同步的后台账号 ID，须有该归属的 manage 授权 |
| `TRACKING_MP_RIGHTS` | 否 | `own`（默认）或 `authorized`，即对这些文章的权属声明 |
| `TRACKING_MP_MAX_ARTICLES` | 否 | 每次读取最新多少篇，1–200，默认 30 |
| `TRACKING_MP_IMPORT_IMAGES=true` | 否 | 导入封面和正文配图，默认关闭，需要 `TRACKING_MEDIA_DIR` |
| `TRACKING_MP_SYNC_INTERVAL_MINUTES` | 否 | 0 或不填：仅手动；否则 15–1440 分钟自动同步一次 |

后台“公众号同步”按钮在 `GET /context` 返回 `mp_sync:true`（已启用且当前账号对该归属有管理权限）时出现。

### 依赖与限制（官方文档，未经验证）

- 使用公众号“发布”能力的 `freepublish/batchget` 接口读取已发布文章；公众号须已认证并具备该接口权限，否则返回如 48001，状态里会显示错误码。
- 一次发布多篇文章时，每篇作为独立素材，ID 为发布记录 ID 加序号。
- 多个进程同时运行是安全的（同步幂等），只会重复调用微信，不会重复建草稿。
- 文章里的视频、音频、投票、小程序卡片等不会同步，正文里的位置顺序也不会保留：图片作为媒体列表附在正文之后。
- 公众号一侧的删除、下架不会反映到本地；本地编辑过的草稿遇到公众号更新时不会合并，只提示。
- 已映射文章的跟进归属不会随 `TRACKING_MP_OWNER` 变化：更换归属需要单独授权，同步会拒绝把已有草稿改给新归属（计入“跳过”，原因显示为“内容未通过校验”）。需要换归属时由人在后台处理，或由负责人决定是否另做迁移。

### 验证步骤（联调时执行并留证据）

1. 用测试公众号配置好变量，`GET /mp-sync` 显示 `enabled:true` 与配置摘要；故意漏配一项，确认保持关闭并列出问题且不含密钥。
2. 点“立即同步”：公众号已发布的文章出现为草稿，标题、正文段落、来源链接正确；再次同步显示“无变化”，没有重复草稿。
3. 在公众号修改一篇文章后再同步：对应草稿更新为新内容；把该草稿发布，再次修改公众号文章并同步：出现新的草稿，原公开版本仍可阅读。
4. 在后台手工改一篇同步来的草稿，再改公众号原文并同步：草稿保持你的修改，结果里出现“需人工处理”。
5. 在公众号删除一篇文章并同步：本地素材不变，结果里列出“公众号已删除”。
6. 用没有 manage 授权的账号作为 `TRACKING_MP_ACTOR`：同步被拒绝且不调用微信。用只读账号点“立即同步”：被拒绝。
7. 开启图片导入（经负责人确认）：配图出现在素材媒体里，访问路径是本系统的媒体地址，不是微信域名；在测试环境确认服务器无法通过该功能访问内网地址。
8. URL Link：开启后发布一篇素材，复制链接在手机打开，进入阅读页并记录一次访问且归因到该分享；确认到期时间不超过 29 天。
