# 图稿补齐第二批 T05—T07 验证记录

本批基于第一批本地 a196c9d524816baa54f049445a1bbb56621e3b82，只改同一React响应式管理后台及其跟踪查询投影。没有生产数据库读写、迁移、资金或用户资料操作。

## 实现

- T05：素材卡按需展开该素材当前筛选的访客，访客可在同卡展开只读会话、页面、事件；保留独立的客户详情与CRM操作入口。折叠即卸载请求；分页回放 first_cursor、失败重试及明确刷新沿用既有合同。意向依据的“查看记录”与卡头折叠分开，避免已展开记录反被关闭。
- T06：Visitor/VisitorContent 增加可选 latest_visit（page_view_id、started_at、visible_ms及素材标识/版本）。仅在授权且当前筛选中计数的page_view里按进入时间选最新，时间相同按稳定ID升序；心跳较晚不冒充新访问。单次时长与累计都使用同窗口裁剪和去重事实，零时长保留；跨窗口只有carry-over的记录不造一次新访问。前端分列“最近一次（当前范围）”和“当前范围累计可见”，未给单次记录时显示未提供，不伪造0。原 last_visit 仍是最近活动，未改定义。
- T07：对照已提供的客户手机、素材桌面、素材手机三张原图，统一暖棕/米白/橙红指标；桌面素材横排和访客行式，手机同卡折叠。44px控件、明确焦点、筛选换行、短屏对话框/安全区、16:9与9:16完整contain预览，不将后台伪装成微信原生页面。
- 独立复核补强：会话轨迹不能从原始事件或保留汇总暴露已撤回、已移归属或失效版本的历史标题。Sessions复用实际素材列表的当前权限校验，并按素材/版本/路由缓存元数据；保留受权访问统计，不回放不可读内容。

编译后CSS的31条静态合同覆盖320/375/390/768/1024/1440及1024×400，检查色彩对比、作用域、触控目标、媒体contain和动态高度。它们不能证明实际浏览器排版、像素一致或键盘运行行为。
