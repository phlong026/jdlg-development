# 首页高清复刻交付包

本目录保存 2026-10-08 首页高清复刻的独立源码快照。原项目 `miniprogram/` 整目录由 Git 忽略，本次只保存交付目录，避免将整个小程序强制加入版本控制。

`home-reference-delivery.zip` 包含 `after/` 当前应用源码、高清图片和相关测试，`before/` 原始应用源码，以及 `manifest.json`、`source.diff`、`rollback.cjs` 和本文。包中所有应用源码和测试文件均记录 SHA-256。`source.diff` 用于审阅文本源码变更。

- 当前应用源码：`pages/index` 的 TS、JS、WXML、SCSS、WXSS、JSON，`pages/aicost` 的 TS、JS，`custom-tab-bar` 的 TS、JS、WXML、SCSS、WXSS，新 `utils/costRegions.ts/js`，`assets/home-reference/hd/` 高清资产。
- 原件来自 `需求文档/首页视觉方案/20261008-用户确认复刻/原首页备份/源码`，共 13 个应用源码文件。
- 9 个首页、造价和分享相关测试仅用于交付；回退脚本不会修改测试。
- 本包不包含全部小程序、服务端、后台或个人开发者配置。它需要配合现有项目使用。

## 应用源码回退

现有 Node 运行时即可使用，无需安装依赖。默认目标是本目录对应仓库中的 `miniprogram/` 项目目录；该项目内部还有一层 `miniprogram/` 页面源码目录。

```sh
node rollback.cjs
```

默认只预演并核对当前应用源码与 `after` 快照 SHA-256 是否一致，不改文件。明确添加 `--apply` 才恢复：

```sh
node rollback.cjs --apply
```

解压到其他位置或对临时副本验证时，显式指定项目目录：

```sh
node rollback.cjs --target /绝对路径/小程序项目目录
node rollback.cjs --target /绝对路径/小程序项目目录 --apply
```

回退只恢复备份中的 13 个应用源码文件，并只删除本清单列出的新增 `costRegions.ts/js` 和 `assets/home-reference/hd/` 文件。它不删除目录，也不触碰其他文件、测试、服务端、后台和开发者配置。任意应用文件在快照后被修改，脚本会在所有写入开始前停止；缺失文件、损坏备份或符号链接也会停止。

恢复旧首页主题后，当前主题相关测试仍保持现状，需要重新匹配原主题预期后再运行。当前测试保留供复刻版本核验，不代表旧版回退后的测试预期。

回退执行期间如发生磁盘或权限错误，脚本返回非零并保留错误上下文；应先检查实际文件状态。回退本身涉及写入，请在现有改动符合交付快照时执行。

## 回退验证

`node --test rollback.test.cjs` 仅创建临时副本，验证默认预演不改动、显式恢复原件全部 SHA-256 一致、清单内新增文件移除、测试及其他文件保留，以及后续他人修改导致整次回退停止。测试不会对真实项目执行回退。

`build-delivery.py` 可重新读取当前源码和原始备份来更新快照、清单、差异与 ZIP；重新打包后应重新运行回退测试。打包脚本不会修改实际小程序。
