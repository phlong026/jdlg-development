# 客户管理一期实施记录

## 设计基线

- 正式入口为原React后台，保留Layout、Topbar、Bookmark和Sidebar，使用App.scss现有设计变量。
- 原小程序线索页面与接口保留；客户管理容器提供访问入口，不复制Go线索逻辑到Java。
- 企微昵称只读；沟通方式写入跟进正文，不新增该字段。
- 资料修改带version；保持已有阶段和待办时间时，不因时间已逾期阻塞仅资料修改。
- 驾驶舱按北京时间和Java权限计算。新增时间来源单独标识，无法确认时间的历史数据不计入今日新增；已知添加时间用于最近新增。
- Java既有业务接口通过受控内部入口复用；账号管理使用独立平台能力路径，不向客户主管开放。
- 统一账号采用managed模式，禁止绕过Go会话从旧CRM Cookie继续访问。
- 原平台访问范围显式迁移；授权表存在后持续强制检查，即使关闭桥接也不放宽顾问权限。缺失授权拒绝，不根据账号名称猜测管理员。
- 企微接入以同步任务结果验证，不增加无对应后端能力的验证连接按钮。

## 实际页面与接口

正式入口 `/admin/customer-management`，栏目通过 `?tab=home/customers/tasks/sync/access/leads` 切换。驾驶舱统计卡携带queue进入列表；旧 `/admin/customer-leads` 保留。平台管理员保留原总控台默认页；crm_only登录后由ProtectedRoute进入客户模块。

浏览器统一前缀 `/api/v1/management/crm`：

| 方法与路径 | 用途 |
| --- | --- |
| GET /context | 当前CRM账号、demo标识 |
| GET /dashboard、/overview | 新增时间/团队聚合；原队列数量 |
| GET /customers、/customers/{id}、/employees | 列表、详情和可用员工 |
| PATCH /customers/{id} | 带version修改资料/归属 |
| POST /customers/{id}/followups | 带version记录跟进 |
| GET /export/customers、/export/followups | 按当前筛选和账号范围导出 |
| GET/POST /sync、POST /sync/events/{id}/retry | 原同步任务及失败事件重试 |
| GET/POST /access、GET /access/employees、POST /access/users | 仅platform_admin管理账号与关联 |

列表返回`{code:0,data:{list,total,page,page_size}}`；page、page_size为数值，page_size映射Java的size，最多100；CSV去掉分页参数，保留业务筛选。错误403显示权限原因，409保留客户表单输入并要求读取最新版本核对，401清理会话回登录；Java内部401或服务故障映射502，避免误当作平台退出。

内部协议使用文档V1规范：版本、key-id、audience、subject、user-id、时间、nonce、method、转义路径、原始查询串、body SHA-256以换行拼接，HMAC-SHA256输出Base64URL无填充；两端共享测试向量。body上限64KB，Go超时20秒、响应上限32MB且不跟随重定向。nonce在数据库唯一插入并定时清理，已认证调用保存资源和结果审计。

## 字段、权限与交互定稿

1. addedTimeSource取event/relation/unknown。今日新增和最近5位排除unknown，按北京时间判断日期；今日新增卡跳转queue=added。阶段new与今天加好友分别统计。
2. 团队按业务ownerId聚合，不按企微好友关系重复计数；顾问驾驶舱、列表、详情、修改、导出由Java统一限制本人范围。
3. 昵称与好友关系只读；电话80字符、需求及跟进2000字符。资料编辑提交完整DTO，保留最新基线中的阶段和下次时间；跟进中/新客户保存跟进必须未来时间，结束阶段清空时间。
4. 平台scope和CRM role分开：platform_admin可配置授权；crm_only+admin是仅管客户的主管；crm_only+staff是顾问，必须绑定有效员工。不会由浏览器传角色冒充操作身份。
5. 采用原后台暖白/浅棕变量、字体、圆角和壳层。手机列表改为卡片，详情/表单为全屏抽屉；焦点限制在弹层内，详情支持Escape关闭，表单取消显式操作。
6. 同步页显示读取参数、回调参数、待处理/失败数和既有任务结果；没有实际任务时为待验证。未配置时禁用发起同步。
