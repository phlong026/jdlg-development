# 四类朋友圈分享卡片

本次仅实现首页、预算入口、预算结果、模板详情；后台截图中的客户管理排版未纳入修改。工作基线为 `9db2693`，未推送、未部署、未上传微信版本。

## 用户看到的行为

- 首页：专用别墅方形封面，标题“甲第灵光 · AI建房助手，建别墅从这里开始”，打开首页。
- 预算入口：专用现代别墅方形封面，标题“10秒估算建房报价，建别墅从这里开始”，打开预算填写页，不携带发送者表单。
- 预算结果：主动点击“准备分享报告”，登录后生成同一份 v4 预算快照；标题与方图均取实际金额、面积和城市。接收者按 `report_id` 读取这份结果，失效时提示重试或重新测算，不回退接收者缓存。
- 模板详情：朋友圈标题“模板名称，建别墅从这里开始”；模板 ID 与短图片标识一起分享，接收者恢复同模板同图。图片更新时明确提示并展示同模板最新图。

朋友圈外层卡片、缩略图尺寸、换行由微信控制。封面没有额外伪造可点击按钮，图片和标题由微信打开对应小程序页面。好友封面保持 5:4，朋友圈独立用 1:1；未准备好时关闭分享菜单，避免默认截图或旧图串入。

2026-10-22 用户要求宣传语单独一行：三个标题已由逗号拼接改为标准 `\n` 换行。实测当前开发者工具把普通换行合并为空格，U+2028 分行符同样没有在指定位置分行，因此最终保留标准 `\n`，不使用填充空格等随屏幕宽度失效的方案。代码返回换行不等于微信已按两行显示；原生卡片没有行布局配置，真机效果待验证，不能承诺固定两行。若要求所有设备严格固定排版，需将两行文字绘制到封面中，而不能修改原生卡片的标题组件。

可按提交反向还原代码，删除注册即可停用新接口；无迁移。已有快照会自然过期。生产代码包体积与真实朋友圈最终外观仍以体验版检查为准。
