### 模板后端测试边界

`bash service/scripts/test-template-update.sh` 将指定生产源文件原样复制到临时模块，使用原 `go.mod` 和 `go.sum`，运行 model/handler 定点测试。它验证本次真实 SQL 构造、条件更新和 HTTP 处理，不等于整服务构建，也不等于真实 MySQL 集成验证。

服务端比较更新保护请求处理时的读写间并发；前端差异提交保护用户未编辑的字段。当前不把它宣称为从打开弹窗到提交全过程的同字段乐观锁。
